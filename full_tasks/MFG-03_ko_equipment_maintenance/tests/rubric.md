# Rubric: MFG-03

## Dimension 1: Schedule Accuracy (Weight: 25%)
- **Excellent (9-10)**: PM schedule with all frequency categories (daily, weekly, monthly, quarterly, annual), priority levels, parts requirements, and time estimates
- **Good (7-8)**: Schedule with 4+ frequencies and some priority/parts/time data
- **Adequate (5-6)**: Basic schedule with 3 frequencies
- **Poor (1-4)**: Minimal schedule data
- **Zero (0)**: No PM schedule

## Dimension 2: Korean Translation (Weight: 25%)
- **Excellent (9-10)**: Maintenance guide with rich Korean (200+ Hangul chars), Korean maintenance terms (장비, 보전, 점검, 교체, etc.), 3+ sections, 1500+ chars
- **Good (7-8)**: Good Korean content with some terminology and structure
- **Adequate (5-6)**: Some Korean with limited terminology
- **Poor (1-4)**: Minimal Korean content
- **Zero (0)**: No Korean guide

## Dimension 3: Parts Mapping (Weight: 20%)
- **Excellent (9-10)**: Trilingual mapping (Japanese, English, Korean) with part numbers from source (NZL-H24, SPK-NXT, etc.), safety stock recommendations, and cost information
- **Good (7-8)**: Multilingual mapping with most part numbers and some recommendations
- **Adequate (5-6)**: Basic mapping with limited languages or parts
- **Poor (1-4)**: Minimal mapping
- **Zero (0)**: No parts mapping

## Dimension 4: History Analysis (Weight: 15%)
- **Excellent (9-10)**: MTBF and MTTR calculated with reasonable values (MTBF: 200-2000h, MTTR: 0.5-10h), failure pattern analysis
- **Good (7-8)**: MTBF/MTTR with pattern analysis
- **Adequate (5-6)**: Some reliability metrics present
- **Poor (1-4)**: Minimal analysis
- **Zero (0)**: No history analysis

## Dimension 5: Completeness (Weight: 15%)
- **Excellent (9-10)**: All 4 output files present, answer.json with all required fields (total_pm_items, annual_cost, critical_items, MTBF, MTTR, spare_parts)
- **Good (7-8)**: Most files and answer fields present
- **Adequate (5-6)**: Some files missing but core content exists
- **Poor (1-4)**: Major gaps in deliverables
- **Zero (0)**: No output

## Language Quality Assessment
- Target language output must be professional quality Korean
- No English fallback in maintenance guide
- Technical terminology must follow Korean maintenance engineering conventions

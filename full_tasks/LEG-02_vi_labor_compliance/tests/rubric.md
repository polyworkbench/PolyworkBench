# Rubric: LEG-02

## Dimension 1: Compliance Identification (Weight: 30%)
- **Excellent (9-10)**: Checklist covers all 3 contracts with compliance status markers, key violations identified (overtime >40h/month, probation period, rest period)
- **Good (7-8)**: 2+ contracts with status markers and some violations
- **Adequate (5-6)**: Basic checklist with partial coverage
- **Poor (1-4)**: Minimal compliance identification
- **Zero (0)**: No compliance checklist

## Dimension 2: Gap Analysis (Weight: 25%)
- **Excellent (9-10)**: 5+ gaps identified with ILO convention references (2+), Vietnamese Labor Code articles (Điều 107, 108, etc.), and specific overtime violation details
- **Good (7-8)**: 3+ gaps with some legal references
- **Adequate (5-6)**: Basic gaps without specific references
- **Poor (1-4)**: Minimal gap identification
- **Zero (0)**: No gap analysis

## Dimension 3: Vietnamese Quality (Weight: 20%)
- **Excellent (9-10)**: Vietnamese diacritics present in checklist and remediation, Vietnamese legal terminology (bộ luật lao động, hợp đồng lao động, người lao động, vi phạm)
- **Good (7-8)**: Vietnamese in both files with some legal terms
- **Adequate (5-6)**: Some Vietnamese content
- **Poor (1-4)**: Minimal Vietnamese
- **Zero (0)**: No Vietnamese content

## Dimension 4: Remediation (Weight: 15%)
- **Excellent (9-10)**: Substantive plan (1000+ chars) with actionable items (sửa đổi, điều chỉnh, bổ sung), contract-specific remediation, structured format
- **Good (7-8)**: Plan with actions and some contract specifics
- **Adequate (5-6)**: Basic remediation plan
- **Poor (1-4)**: Minimal plan
- **Zero (0)**: No remediation plan

## Dimension 5: Legal Accuracy (Weight: 10%)
- **Excellent (9-10)**: Correct identification of overtime limit violations (60h/50h vs 40h max), probation violations (90 days), rest period gaps, with severity levels
- **Good (7-8)**: Most key facts correctly identified
- **Adequate (5-6)**: Some factual accuracy
- **Poor (1-4)**: Significant inaccuracies
- **Zero (0)**: No legal analysis

## Language Quality Assessment
- Target language output must be professional quality Vietnamese
- No English fallback in compliance checklist and remediation plan
- Technical terminology must follow Vietnamese labor law conventions

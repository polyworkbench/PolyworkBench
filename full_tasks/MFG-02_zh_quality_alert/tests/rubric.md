# Rubric: MFG-02

## Dimension 1: Defect Detection (Weight: 30%)
- **Excellent (9-10)**: Total defects in range (60-90), critical defects identified (5-12), classification with all severity levels (Critical, Major, Minor), structured output
- **Good (7-8)**: Defect counts reasonable with most severity levels
- **Adequate (5-6)**: Some defect data with partial classification
- **Poor (1-4)**: Minimal defect detection
- **Zero (0)**: No defect data

## Dimension 2: Root Cause Analysis (Weight: 25%)
- **Excellent (9-10)**: 5M1E methodology applied (Man, Machine, Material, Method, Measurement, Environment), key causes identified (temperature/reflow, nozzle, feeder), top root cause named
- **Good (7-8)**: 4+ categories with some key causes
- **Adequate (5-6)**: Basic root cause with 2-3 categories
- **Poor (1-4)**: Minimal root cause content
- **Zero (0)**: No root cause analysis

## Dimension 3: Chinese Alert (Weight: 20%)
- **Excellent (9-10)**: Quality alert with rich Chinese content (100+ chars), all sections (alert level, scope, description, containment, root cause, corrective), 800+ chars
- **Good (7-8)**: Chinese alert with 4-5 sections
- **Adequate (5-6)**: Some Chinese alert content with limited sections
- **Poor (1-4)**: Minimal Chinese content
- **Zero (0)**: No quality alert

## Dimension 4: Classification (Weight: 15%)
- **Excellent (9-10)**: Defect types classified (solder, misalignment, missing, bridge, cosmetic), affected batches listed, frequency data included
- **Good (7-8)**: Most defect types with batch info
- **Adequate (5-6)**: Some classification present
- **Poor (1-4)**: Minimal classification
- **Zero (0)**: No classification

## Dimension 5: Corrective Actions (Weight: 10%)
- **Excellent (9-10)**: Actions with short-term and long-term measures, responsibility assignment, and deadlines
- **Good (7-8)**: Actions with 3 of 4 elements
- **Adequate (5-6)**: Basic actions with 2 elements
- **Poor (1-4)**: Minimal action content
- **Zero (0)**: No corrective actions

## Language Quality Assessment
- Target language output must be professional quality Chinese
- No English fallback in quality alert document
- Technical terminology must follow Chinese manufacturing/QC conventions

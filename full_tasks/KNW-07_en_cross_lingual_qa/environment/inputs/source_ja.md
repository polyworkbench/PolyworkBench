# 2024年度 日本テクノロジー産業動向レポート

**発行機関：** 経済産業省 産業技術環境局  
**発行日：** 2024年11月  
**対象期間：** 2024年4月〜9月（上半期）

## 1. 半導体産業

日本の半導体産業は回復基調にある。2024年上半期の半導体売上高は**2兆4,300億円**（約162億ドル）で、前年同期比**14.7%増**となった。

主要企業の動向：
- **ルネサスエレクトロニクス**：車載半導体の売上高が前年比18.2%増。28nm以下の先端プロセスの生産能力を2025年までに**40%拡大**する計画を発表。
- **東京エレクトロン**：半導体製造装置の受注額が前年比**23.5%増**の1兆2,800億円。EUV関連装置の需要が特に堅調。
- **ラピダス**：2nmプロセスの試作ラインが2024年9月に稼働開始。量産は**2027年**を目標としている。

## 2. AI・クラウド市場

国内AI市場規模は**1兆8,700億円**（約125億ドル）に達し、前年比**32.4%**の成長を記録した。

分野別市場規模：
- 生成AI関連：4,200億円（前年比**186%増**）
- 機械学習プラットフォーム：3,800億円
- 自然言語処理：2,900億円
- コンピュータビジョン：3,100億円

日本企業のAI投資額：
- トヨタ自動車：AI研究開発に年間**1,800億円**を投資
- ソフトバンクグループ：AIインフラに**5,000億円**の投資計画（2024-2026年）
- NTTグループ：大規模言語モデル「tsuzumi」の商用展開開始、開発費**600億円**

## 3. ロボティクス産業

日本のロボット生産額は**9,420億円**で世界シェア**45.2%**を維持。
- 産業用ロボット出荷台数：**23万4,000台**（前年比8.3%増）
- サービスロボット市場：1,840億円（前年比**22.1%増**）
- 協働ロボット：売上高が前年比**34.7%増**と最も高い成長率

## 4. 電気自動車（EV）関連

国内EV販売台数は**18万7,000台**（乗用車市場の8.2%）。
- 全固体電池の開発状況：トヨタが2027-2028年の実用化を発表
- 充電インフラ：全国の急速充電器設置数が**4万2,000基**に到達
- EV用バッテリー国内生産能力：年間**50GWh**（2025年目標：80GWh）

## 5. 量子コンピューティング

政府の量子技術戦略予算：**1,250億円**（2024年度）
- 富士通の超伝導量子コンピュータ：**1,000量子ビット**を達成（2024年8月）
- 理化学研究所：量子誤り訂正の新手法を開発、エラー率を**0.1%以下**に抑制
- 量子コンピューティング関連の特許出願数：日本は世界第**3位**（全体の12.8%）

# Rubric: KNW-07

## Dimension 1: Answer Accuracy (Weight: 35%)
- **Excellent (9-10)**: All questions answered correctly with proper source attribution, factual claims verified against multiple sources
- **Good (7-8)**: Most answers correct with sources cited
- **Adequate (5-6)**: Some correct answers
- **Poor (1-4)**: Many incorrect answers
- **Zero (0)**: No answers

## Dimension 2: Citation Quality (Weight: 20%)
- **Excellent (9-10)**: Each answer cites specific sources with page/section references, multilingual source handling, proper attribution format
- **Good (7-8)**: Citations present for most answers
- **Adequate (5-6)**: Some citations included
- **Poor (1-4)**: Minimal citations
- **Zero (0)**: No citations

## Dimension 3: Verification Quality (Weight: 20%)
- **Excellent (9-10)**: Cross-lingual verification performed, conflicting information resolved, reliability assessment for each claim
- **Good (7-8)**: Some verification with conflict resolution
- **Adequate (5-6)**: Basic verification noted
- **Poor (1-4)**: Minimal verification
- **Zero (0)**: No verification

## Dimension 4: Confidence Calibration (Weight: 15%)
- **Excellent (9-10)**: Confidence scores well-calibrated (verified claims higher than unverified), reasonable spread of confidence levels
- **Good (7-8)**: Generally good calibration
- **Adequate (5-6)**: Confidence scores present but poorly calibrated
- **Poor (1-4)**: Uniform or random confidence
- **Zero (0)**: No confidence scores

## Dimension 5: Completeness (Weight: 10%)
- **Excellent (9-10)**: Fact sheet with all claims addressed, verification report (1000+ words, 3+ headers), citation data complete
- **Good (7-8)**: Most elements complete
- **Adequate (5-6)**: Partial completeness
- **Poor (1-4)**: Major gaps
- **Zero (0)**: No output

## Language Quality Assessment
- Target language output must be professional quality English
- Source languages must be properly handled without mistranslation
- Technical terminology must be domain-appropriate for cross-lingual information retrieval

# リチウムイオン電池の長期サイクル劣化特性に関する研究：LFP正極材の優位性

**電気化学会誌, 第91巻 第4号, pp. 312-338, 2023年12月**

*田中健太郎¹, 山本美咲², 佐藤大輔¹*

¹ 東京大学 工学系研究科 化学システム工学専攻  
² 京都大学 エネルギー科学研究科

---

## 要旨

本研究では、リチウムイオン電池（LIB）の長期サイクル劣化特性について、LiFePO₄（LFP）正極材を中心に系統的な評価を行った。20-25°Cの温度範囲において1C充放電条件で試験を行った結果、80% SoH到達サイクル数は平均1200サイクルであることが確認された。また、3Cを超える高率充電が劣化を顕著に加速させることを明らかにした。本研究の結果に基づき、定置型蓄電システムおよび電気自動車用途にはLFP正極材を推奨する。

**キーワード**: リチウムイオン電池、サイクル劣化、LFP、寿命予測、充電レート

---

## 1. 緒言

リチウムイオン電池（LIB）の長寿命化は、電気自動車（EV）および定置型エネルギー貯蔵システム（ESS）の普及における最重要課題の一つである。近年、NMC系（LiNiₓMnᵧCoᵤO₂）やLFP系（LiFePO₄）など、様々な正極材が提案されているが、長期的なサイクル寿命の観点からは依然として議論が続いている。

本研究では、LFP正極材を用いたLIBの劣化挙動を詳細に分析し、運転条件と寿命の関係を定量的に明らかにすることを目的とする。

## 2. 実験方法

### 2.1 セル作製
- 正極: LiFePO₄（LFP）、面積容量 2.8 mAh/cm²
- 負極: 人造黒鉛、面積容量 3.2 mAh/cm²
- 電解液: 1M LiPF₆ in EC:DEC (3:7 v/v)
- セパレータ: PP/PE/PP三層構造（厚さ20μm）

### 2.2 試験条件
- 温度: 20°C, 25°C, 30°C, 40°C, 50°C
- 充電: CC-CV方式、上限電圧 3.65V
- 放電: CC方式、下限電圧 2.5V
- 充電レート: 0.5C, 1C, 2C, 3C, 4C
- サイクル数: 最大2000サイクル

### 2.3 分析手法
- 容量測定: 50サイクル毎に0.2C基準容量測定
- EIS: 100サイクル毎に電気化学インピーダンス分光法
- 事後分析: XRD、SEM、FIB-TEMによる電極構造解析

## 3. 結果と考察

### 3.1 サイクル寿命特性

20-25°Cの最適温度範囲において、1C充放電条件でのLFPセルの容量維持率は以下の通りであった：

| サイクル数 | 容量維持率 (%) | SoH状態 |
|-----------|--------------|---------|
| 0 | 100.0 | 正常 |
| 200 | 97.8 | 正常 |
| 400 | 95.2 | 正常 |
| 600 | 91.8 | 正常 |
| 800 | 87.5 | 正常 |
| 1000 | 83.2 | 注意 |
| 1200 | 80.0 | EOL基準到達 |
| 1500 | 73.5 | EOL以降 |

**主要結果**: 80% SoH到達時点は平均1200サイクル（標準偏差 ±45サイクル、n=10）

### 3.2 温度影響

最適運転温度範囲は20-25°Cであることが確認された。温度別寿命比較：

| 温度 (°C) | 80% SoH到達サイクル | 相対寿命 |
|----------|-------------------|---------|
| 0 | 680 | 0.57 |
| 15 | 980 | 0.82 |
| 20 | 1150 | 0.96 |
| 25 | 1200 | 1.00 |
| 30 | 1080 | 0.90 |
| 40 | 780 | 0.65 |
| 50 | 520 | 0.43 |

20-25°Cの範囲で最長寿命を示し、この温度帯ではSEI膜の安定的な成長と電解液分解の抑制が両立することが確認された。

### 3.3 充電レート影響

高率充電が劣化に与える影響を定量的に分析した結果：

| 充電レート | 80% SoHサイクル | 劣化加速率 |
|-----------|---------------|----------|
| 0.5C | 1450 | 基準比 +21% 寿命延長 |
| 1C | 1200 | 基準 |
| 2C | 980 | 18% 加速 |
| 3C | 720 | 40% 加速 |
| 4C | 480 | 60% 加速 |

**主要結果**: 3Cを超える充電において劣化が顕著に加速する。2C充電では劣化加速は18%と比較的軽微であり、実用上許容可能な範囲と判断される。3C以上で40%以上の加速が観察され、これはリチウム析出と負極SEI層の急速成長に起因する。

### 3.4 正極材推奨

本研究結果を総合すると、電気自動車および定置型蓄電池にはLFP正極材を強く推奨する。理由は以下の通り：

1. **圧倒的なサイクル寿命**: 1200サイクル（NMC811比 +50%）
2. **高い安全性**: 熱暴走リスクが極めて低い
3. **コスト優位性**: コバルトフリーによる原料コスト低減
4. **環境適合性**: レアメタル使用量の削減

エネルギー密度ではNMC811に劣るものの（LFP: 170-180 Wh/kg vs NMC811: 250-280 Wh/kg）、総所有コスト（TCO）の観点ではLFPが優位である。

## 4. 結論

1. LFPセルは20-25°C、1C条件で1200サイクルの80% SoH寿命を示す。
2. 最適温度範囲は20-25°Cであり、この範囲でSEI安定性が最大化される。
3. 3Cを超える高率充電が劣化を顕著に加速する（40%以上）。2Cでは18%の軽微な加速にとどまる。
4. 総合的に、LFP正極材がEVおよびESS用途に最適である。

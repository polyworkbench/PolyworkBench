# Rubric: LEG-07

## Dimension 1: Regulatory Comparison (Weight: 30%)
- **Excellent (9-10)**: Comprehensive comparison across all 4 jurisdictions (China/PIPL, Korea/PIPA, Vietnam/PDPD, Japan/APPI) covering 5+ dimensions (scope, consent, cross-border, breach notification, penalties)
- **Good (7-8)**: 4 jurisdictions with 3-4 dimensions
- **Adequate (5-6)**: 3 jurisdictions or limited dimensions
- **Poor (1-4)**: Minimal comparison
- **Zero (0)**: No comparison output

## Dimension 2: Factual Accuracy (Weight: 25%)
- **Excellent (9-10)**: Key facts correct (72h breach timelines, DPO requirements per jurisdiction, fine percentages, children age thresholds, cross-border mechanisms)
- **Good (7-8)**: Most key facts accurate
- **Adequate (5-6)**: Some facts correct
- **Poor (1-4)**: Significant inaccuracies
- **Zero (0)**: No factual content

## Dimension 3: English Report Quality (Weight: 20%)
- **Excellent (9-10)**: Well-structured English report with tables/matrices, clear headings, actionable compliance guidance, 2000+ words
- **Good (7-8)**: Good English report with structure
- **Adequate (5-6)**: Basic report present
- **Poor (1-4)**: Minimal report
- **Zero (0)**: No report

## Dimension 4: Practical Guidance (Weight: 15%)
- **Excellent (9-10)**: Specific compliance recommendations per jurisdiction, gap identification, priority actions for multi-jurisdiction operations
- **Good (7-8)**: Recommendations with some jurisdiction-specific guidance
- **Adequate (5-6)**: General guidance
- **Poor (1-4)**: Minimal guidance
- **Zero (0)**: No practical guidance

## Dimension 5: Completeness (Weight: 10%)
- **Excellent (9-10)**: All deliverables present, answer.json with correct regulatory details
- **Good (7-8)**: Most deliverables present
- **Adequate (5-6)**: Some files missing
- **Poor (1-4)**: Major gaps
- **Zero (0)**: No output

## Language Quality Assessment
- Target language output must be professional quality English
- Technical terminology must be domain-appropriate for data protection law
- Regulatory citations must be precise and verifiable

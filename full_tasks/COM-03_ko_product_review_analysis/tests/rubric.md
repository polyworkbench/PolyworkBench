# Rubric: COM-03

## Dimension 1: Sentiment Accuracy (Weight: 25%)
- **Excellent (9-10)**: All 50 reviews analyzed with correct sentiment labels (positive/negative/neutral) and valid polarity scores (-1.0 to 1.0)
- **Good (7-8)**: 40+ reviews with proper labels and scores
- **Adequate (5-6)**: 25+ reviews analyzed with some labeling inconsistencies
- **Poor (1-4)**: Few reviews analyzed or many incorrect labels
- **Zero (0)**: No sentiment analysis produced

## Dimension 2: Issue Extraction (Weight: 25%)
- **Excellent (9-10)**: Issues categorized using taxonomy (QUAL-HW, QUAL-SW, PERF, FIT, TRUST, SVC), mapped to individual reviews, reasonable issue count (25-35)
- **Good (7-8)**: Most issues categorized with taxonomy references, adequate coverage
- **Adequate (5-6)**: Some categorization present but incomplete taxonomy usage
- **Poor (1-4)**: Minimal issue extraction or no categorization
- **Zero (0)**: No issue extraction

## Dimension 3: Korean Report (Weight: 20%)
- **Excellent (9-10)**: Substantive Korean executive report (500+ chars) with clear structure (4+ sections), recommendations using Korean business terminology
- **Good (7-8)**: Korean report with good structure and some recommendations
- **Adequate (5-6)**: Report in Korean but short or poorly structured
- **Poor (1-4)**: Minimal Korean content or no structure
- **Zero (0)**: No Korean report

## Dimension 4: English Appendix (Weight: 15%)
- **Excellent (9-10)**: Complete English data appendix with sentiment distribution, categories, issues, trends, and statistics
- **Good (7-8)**: English appendix with most data categories present
- **Adequate (5-6)**: Appendix exists but missing key data sections
- **Poor (1-4)**: Minimal English data appendix
- **Zero (0)**: No English appendix

## Dimension 5: Statistics (Weight: 15%)
- **Excellent (9-10)**: Summary statistics with correct sentiment distribution, averages, counts, and key metrics
- **Good (7-8)**: Statistics present with distribution data and basic metrics
- **Adequate (5-6)**: Some statistics but missing distribution or metrics
- **Poor (1-4)**: Minimal statistical output
- **Zero (0)**: No statistics file

## Language Quality Assessment
- Target language output must be professional quality Korean
- No English fallback in the executive report
- Technical terminology must be domain-appropriate for product analytics

# 한국어 제품 리뷰 분석 및 이중 언어 보고서 작성

`/workspace/inputs/` 에 있는 파일들을 활용하여 50개의 한국어 제품 리뷰를 분석하고, 감성 분석 및 이슈 추출을 수행한 후 이중 언어 보고서(한국어 경영진 요약 + 영어 데이터 부록)를 작성하세요.

요구사항:
- `reviews_ko.txt`에 있는 50개 한국어 리뷰를 분석하여 각 리뷰의 감성(긍정/부정/중립)을 판별하고 `sentiment_analysis.json`에 결과를 저장 (리뷰ID, 원문, 감성점수 -1.0~1.0, 감성라벨, 핵심 키워드)
- `category_taxonomy_en.json`의 이슈 분류 체계를 활용하여 각 리뷰에서 제기된 이슈를 카테고리별로 분류
- 제품 사양(`product_specs_zh.json`)과 리뷰 내용을 대조하여 사양 불일치 또는 과대광고 관련 이슈를 식별
- 한국어 이슈 보고서(`issues_report_ko.md`) 작성: 경영진 요약, 주요 이슈 Top 5, 카테고리별 분석, 개선 권고사항 포함
- 영어 데이터 부록(`data_appendix_en.json`) 작성: 감성 분포, 카테고리별 이슈 건수, 시계열 트렌드 데이터 포함
- 통계 요약(`summary_stats.json`): 전체 감성 분포, 평균 평점, 이슈 카테고리별 건수, 긍정/부정 비율 등
- 모든 한국어 출력물은 자연스러운 비즈니스 한국어로 작성하고, 영어 부록은 데이터 분석 용어를 적절히 사용

결과물을 `/workspace/output/`에 저장하고, 최종 요약을 `/workspace/answer.json`에 작성하세요.

**重要：所有产出必须写入磁盘文件，不要只回复文本。用 bash 命令创建目录、写文件、执行脚本。**

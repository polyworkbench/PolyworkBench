# Rubric: MFG-08

## Dimension 1: Declaration Compliance (Weight: 30%)
- **Excellent (9-10)**: French Declaration of Conformity with manufacturer info, all directives (2014/35, 2014/30, 2011/65), harmonized standards (EN 62368, 55032, 55035), proper format, and signature block
- **Good (7-8)**: Declaration with most directives and standards
- **Adequate (5-6)**: Declaration exists with partial compliance elements
- **Poor (1-4)**: Minimal declaration content
- **Zero (0)**: No declaration

## Dimension 2: French Quality (Weight: 25%)
- **Excellent (9-10)**: Both declaration and technical report in proper French, rich technical terminology (essai, conformité, directive, norme, sécurité, compatibilité électromagnétique)
- **Good (7-8)**: French in both documents with some technical terms
- **Adequate (5-6)**: French present but limited terminology
- **Poor (1-4)**: Minimal French content
- **Zero (0)**: No French content

## Dimension 3: Technical Accuracy (Weight: 20%)
- **Excellent (9-10)**: Test summary with GB→EN standard mapping (GB4943→EN 62368), pass/fail results for each test, 10+ test items
- **Good (7-8)**: Mapping with results and multiple items
- **Adequate (5-6)**: Basic mapping present
- **Poor (1-4)**: Minimal technical data
- **Zero (0)**: No test summary

## Dimension 4: Standards Mapping (Weight: 15%)
- **Excellent (9-10)**: Technical report covering all test areas (LVD safety, EMC, RoHS) with risk assessment
- **Good (7-8)**: Report with 2+ test areas
- **Adequate (5-6)**: Basic report with 1 area
- **Poor (1-4)**: Minimal report
- **Zero (0)**: No technical report

## Dimension 5: Completeness (Weight: 10%)
- **Excellent (9-10)**: CE checklist with items covered (LVD, EMC, RoHS, documentation, marking) and status indicators (conforme/non conforme)
- **Good (7-8)**: Checklist with most items and statuses
- **Adequate (5-6)**: Basic checklist present
- **Poor (1-4)**: Minimal checklist
- **Zero (0)**: No checklist

## Language Quality Assessment
- Target language output must be professional quality French
- No English fallback in declaration or technical report
- Technical terminology must follow EU CE marking and French regulatory conventions

# Rubric: MFG-10

## Dimension 1: Data Normalization (Weight: 20%)
- **Excellent (9-10)**: Plant comparison with all 5 plants present, common English schema (OEE, yield, output, etc.), and normalized units (per-line or per-capita)
- **Good (7-8)**: 4+ plants with common schema
- **Adequate (5-6)**: 3 plants with some normalization
- **Poor (1-4)**: Minimal normalization
- **Zero (0)**: No comparison data

## Dimension 2: Inconsistency Detection (Weight: 20%)
- **Excellent (9-10)**: 4+ findings detected, constant-value anomalies flagged (Japan/Korea/China), 3+ plants flagged, evidence provided (variance, coefficient)
- **Good (7-8)**: 2-3 inconsistencies with constant-value detection
- **Adequate (5-6)**: 1-2 inconsistencies found
- **Poor (1-4)**: Minimal detection
- **Zero (0)**: No findings

## Dimension 3: Comparative Analysis (Weight: 20%)
- **Excellent (9-10)**: Benchmark report with rankings, strengths/weaknesses analysis, and data quality assessment section
- **Good (7-8)**: Report with rankings and some analysis
- **Adequate (5-6)**: Basic report without full analysis
- **Poor (1-4)**: Minimal comparative content
- **Zero (0)**: No benchmark report

## Dimension 4: Script Quality (Weight: 15%)
- **Excellent (9-10)**: Python script reading all 5 plant CSVs, handling encodings, performing statistical analysis (std, mean, variance), and producing outputs
- **Good (7-8)**: Script with 3-4 capabilities
- **Adequate (5-6)**: Basic script with 2 capabilities
- **Poor (1-4)**: Minimal script
- **Zero (0)**: No script

## Dimension 5: Report Quality (Weight: 15%)
- **Excellent (9-10)**: Executive-format markdown with tables/lists, all plants discussed, and actionable recommendations
- **Good (7-8)**: Good format with most plants and some actions
- **Adequate (5-6)**: Basic report format
- **Poor (1-4)**: Minimal report
- **Zero (0)**: No report

## Language Quality Assessment
- Target language output must be professional quality English
- Technical terminology must be domain-appropriate for manufacturing benchmarking
- Statistical findings must be clearly presented with supporting evidence

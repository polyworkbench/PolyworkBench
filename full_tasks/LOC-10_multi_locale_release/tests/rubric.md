# Rubric: LOC-10

## Dimension 1: Consistency Check (Weight: 20%)
- **Excellent (9-10)**: Cross-locale consistency verified with no unintentional variations between language versions
- **Good (7-8)**: Good consistency with minor issues noted
- **Adequate (5-6)**: Some inconsistencies found but not all
- **Poor (1-4)**: No consistency checking
- **Zero (0)**: Not attempted or no relevant output

## Dimension 2: QA Thoroughness (Weight: 20%)
- **Excellent (9-10)**: Thorough QA covering all locales with specific issue identification and categorization
- **Good (7-8)**: Good QA for most locales
- **Adequate (5-6)**: Partial QA coverage
- **Poor (1-4)**: Minimal QA performed
- **Zero (0)**: Not attempted or no relevant output

## Dimension 3: Changelog Quality (Weight: 20%)
- **Excellent (9-10)**: Detailed changelog documenting all locale-specific changes with rationale
- **Good (7-8)**: Good changelog with most changes noted
- **Adequate (5-6)**: Basic changelog
- **Poor (1-4)**: No changelog
- **Zero (0)**: Not attempted or no relevant output

## Dimension 4: Issue Detection (Weight: 15%)
- **Excellent (9-10)**: Specific localization issues identified (truncation, encoding, cultural, formatting)
- **Good (7-8)**: Most issue types detected
- **Adequate (5-6)**: Some issues found
- **Poor (1-4)**: No issues detected
- **Zero (0)**: Not attempted or no relevant output

## Dimension 5: Locale Coverage (Weight: 15%)
- **Excellent (9-10)**: All target locales thoroughly reviewed and validated
- **Good (7-8)**: Most locales covered
- **Adequate (5-6)**: Partial locale coverage
- **Poor (1-4)**: Few locales reviewed
- **Zero (0)**: Not attempted or no relevant output

## Dimension 6: Report Quality (Weight: 10%)
- **Excellent (9-10)**: Clear release readiness report with go/no-go recommendation per locale
- **Good (7-8)**: Good report with recommendations
- **Adequate (5-6)**: Basic report
- **Poor (1-4)**: No report
- **Zero (0)**: Not attempted or no relevant output

## Language Quality Assessment
- Target language output must be professional quality in all target locales
- No unwarranted English fallback (each locale output must be in specified target language)
- Technical terminology must be domain-appropriate

# ShopEasy v3.2.0 Release Notes

## What's New

### Enhanced Shopping Experience
- **Smart Search Suggestions**: Get personalized product recommendations as you type in the search bar
- **Improved Cart Management**: Swipe actions for quick item removal and quantity updates
- **Wishlist Sharing**: Share your wishlist with friends via link or social media

### Payment & Orders
- **Apple Pay / Google Pay Integration**: One-tap checkout for faster purchases
- **Real-time Order Tracking**: Live map showing your delivery progress
- **Split Payment**: Pay with multiple payment methods in a single order

### Account & Settings
- **Dark Mode**: New dark theme for comfortable nighttime browsing
- **Notification Preferences**: Granular control over which notifications you receive
- **Privacy Dashboard**: New centralized privacy controls and data management

## Bug Fixes
- Fixed crash when applying expired coupons
- Resolved image loading issues on slow connections
- Fixed incorrect item count display in cart badge
- Addressed authentication timeout on background return

## Performance Improvements
- 40% faster app startup time
- Reduced memory usage by 25%
- Optimized image caching for smoother scrolling

## System Requirements
- iOS 15.0 or later
- Android 10 or later
- 100 MB free storage space

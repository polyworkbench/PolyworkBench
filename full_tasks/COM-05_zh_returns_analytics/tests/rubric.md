# Rubric: COM-05

## Dimension 1: Data Extraction (Weight: 25%)
- **Excellent (9-10)**: Both markets (Russia, Vietnam) covered with proper reason code extraction (DEFECTIVE, QUALITY, WRONG_SIZE, etc.) and SKU matching across sources
- **Good (7-8)**: Both markets present with most reason codes and SKU references
- **Adequate (5-6)**: One market covered or partial reason extraction
- **Poor (1-4)**: Minimal data extraction from sources
- **Zero (0)**: No extraction output

## Dimension 2: Analytics Accuracy (Weight: 25%)
- **Excellent (9-10)**: Dashboard and category breakdown with return rates, time trends (Oct/Nov), and proper percentage calculations
- **Good (7-8)**: Analytics present with rates and some trend data
- **Adequate (5-6)**: Basic analytics without trends or rates
- **Poor (1-4)**: Minimal computational output
- **Zero (0)**: No analytics files

## Dimension 3: Chinese Report (Weight: 20%)
- **Excellent (9-10)**: Substantive Chinese recommendations (500+ chars) with structured sections, actionable improvements, and proper Chinese business terminology
- **Good (7-8)**: Chinese report with structure and some actionable content
- **Adequate (5-6)**: Chinese content present but short or poorly structured
- **Poor (1-4)**: Minimal Chinese content
- **Zero (0)**: No Chinese report

## Dimension 4: Dashboard Completeness (Weight: 15%)
- **Excellent (9-10)**: Dashboard data structured for visualization with labels, values, and market comparisons (Russia vs Vietnam)
- **Good (7-8)**: Dashboard data with chart-ready structure and some comparisons
- **Adequate (5-6)**: Dashboard exists but not well-structured for visualization
- **Poor (1-4)**: Minimal dashboard data
- **Zero (0)**: No dashboard file

## Dimension 5: Recommendations (Weight: 15%)
- **Excellent (9-10)**: Root cause analysis with prioritized recommendations and policy references (return rate thresholds)
- **Good (7-8)**: Recommendations with some root cause and prioritization
- **Adequate (5-6)**: Basic recommendations without prioritization
- **Poor (1-4)**: Vague or untargeted suggestions
- **Zero (0)**: No recommendations

## Language Quality Assessment
- Target language output must be professional quality Chinese
- No English fallback in the recommendations report
- Technical terminology must be domain-appropriate for returns analytics

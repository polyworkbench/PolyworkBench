# Global Returns & Refund Policy

**Version:** 3.1  
**Effective Date:** January 1, 2024  
**Applicable Markets:** Russia, Vietnam, France, Korea

## 1. ELIGIBILITY WINDOW

- **Standard Products:** 30 calendar days from delivery date
- **Electronics:** 14 calendar days from delivery date (EU consumer rights aligned)
- **Food & Beverage:** 7 calendar days from delivery date (sealed products only)
- **Cosmetics:** 14 calendar days from delivery date (sealed/unused products only)

## 2. VALID RETURN REASONS

### 2.1 Unconditional Returns (Full Refund)
- **DEFECTIVE:** Product has manufacturing defect or stops functioning within warranty period
- **DAMAGED:** Product arrived damaged due to shipping/packaging issues
- **WRONG_ITEM:** Received different product than ordered

### 2.2 Conditional Returns (Full Refund with Verification)
- **NOT_AS_DESCRIBED:** Product specifications or appearance significantly differ from listing
- **WRONG_SIZE:** Size does not match published size chart (requires measurement evidence)

### 2.3 Conditional Returns (Partial Refund - 80%)
- **QUALITY:** Product quality below reasonable expectations but not technically defective
- **COMFORT:** Product does not fit/suit customer (subjective preference)
- **CHANGED_MIND:** Customer no longer wants the product (must be unused, sealed)

### 2.4 Special Cases (Case-by-case Review)
- **ALLERGIC:** Allergic reaction to product - full refund + medical cost reimbursement up to $50 equivalent
- **COUNTERFEIT:** Suspected counterfeit product - full refund + investigation initiated

## 3. RETURN CONDITIONS

- Product must be in original packaging (exception: DEFECTIVE and ALLERGIC)
- All accessories and documentation must be included
- Customer must provide order number and reason code
- Photo evidence required for: DAMAGED, DEFECTIVE, NOT_AS_DESCRIBED, WRONG_SIZE
- Medical certificate required for: ALLERGIC

## 4. REFUND PROCESSING

- **Timeline:** Refund processed within 5-7 business days of receiving returned item
- **Method:** Original payment method
- **Shipping Cost:**
  - DEFECTIVE, DAMAGED, WRONG_ITEM, NOT_AS_DESCRIBED: Seller pays return shipping
  - QUALITY, COMFORT, CHANGED_MIND: Customer pays return shipping
  - ALLERGIC: Seller pays return shipping

## 5. EXCLUSIONS

Returns are NOT accepted for:
- Products outside the eligibility window
- Products without proof of purchase
- Products that have been intentionally damaged
- Food products that have been opened/consumed
- Cosmetics that have been opened and used (exception: ALLERGIC with evidence)

## 6. CROSS-BORDER CONSIDERATIONS

- Return shipping to origin country (China) is not required for items under $20 value
- Local warehouse returns available for Russia (Moscow) and Vietnam (Ho Chi Minh City)
- Customs duties on return shipments are seller's responsibility
- Language requirement: Return form must be completed in English or local language

## 7. QUALITY ESCALATION

- If return rate for any SKU exceeds 5% in a rolling 30-day period: automatic quality review triggered
- If return rate exceeds 10%: product listing suspended pending investigation
- Three or more ALLERGIC reports for same product: immediate listing removal

## 8. METRICS & REPORTING

- Overall target return rate: < 3%
- Acceptable return rate by category:
  - Electronics: < 4%
  - Fashion/Accessories: < 5%
  - Home & Kitchen: < 2%
  - Food & Beverage: < 1%
  - Beauty & Personal Care: < 3%

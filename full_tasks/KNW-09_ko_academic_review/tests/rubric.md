# Rubric: KNW-09

## Dimension 1: Review Quality (Weight: 25%)
- **Excellent (9-10)**: Detailed review comments identifying strengths, weaknesses, methodology issues, and contribution assessment, well-structured markdown
- **Good (7-8)**: Good review with most elements
- **Adequate (5-6)**: Basic review comments
- **Poor (1-4)**: Minimal review content
- **Zero (0)**: No review comments

## Dimension 2: Korean Academic Style (Weight: 25%)
- **Excellent (9-10)**: Professional Korean academic register with proper review terminology, formal expressions, rich Hangul content in both review and suggestions
- **Good (7-8)**: Good Korean academic writing
- **Adequate (5-6)**: Some Korean academic content
- **Poor (1-4)**: Minimal Korean
- **Zero (0)**: No Korean content

## Dimension 3: Reference Integration (Weight: 20%)
- **Excellent (9-10)**: Reference comparison analyzing cited works, identifying missing references, evaluating citation appropriateness
- **Good (7-8)**: Good reference comparison with analysis
- **Adequate (5-6)**: Basic reference listing
- **Poor (1-4)**: Minimal reference content
- **Zero (0)**: No reference comparison

## Dimension 4: Constructiveness (Weight: 15%)
- **Excellent (9-10)**: Revision suggestions that are specific, actionable, and constructive with clear improvement paths
- **Good (7-8)**: Mostly constructive suggestions
- **Adequate (5-6)**: Some constructive content
- **Poor (1-4)**: Vague or unhelpful suggestions
- **Zero (0)**: No revision suggestions

## Dimension 5: Evaluation Matrix (Weight: 15%)
- **Excellent (9-10)**: Structured evaluation matrix with scoring criteria, consistent assessment across dimensions
- **Good (7-8)**: Matrix with most criteria
- **Adequate (5-6)**: Basic evaluation structure
- **Poor (1-4)**: Minimal evaluation
- **Zero (0)**: No evaluation matrix

## Language Quality Assessment
- Target language output must be professional quality Korean
- No English fallback in review comments and revision suggestions
- Technical terminology must follow Korean academic peer review conventions

# 한국 수학 교수법 보충 자료

## 교수 철학

### 개념 이해 중심 접근법
한국 수학 교육은 단순한 공식 암기보다 개념의 깊은 이해를 강조합니다.

**핵심 원칙:**
1. **구체 → 추상** (Concrete → Abstract): 구체적인 예시에서 시작하여 추상적 개념으로 이동
2. **시각화**: 모든 개념을 그림, 그래프, 도표로 시각화
3. **단계적 학습**: 쉬운 것에서 어려운 것으로 점진적 진행
4. **오개념 사전 차단**: 학생들이 흔히 하는 실수를 미리 예방

## 수업 구조 (45분 기준)

### 도입 (5분)
- 전시 학습 확인 (이전 수업 복습)
- 동기 유발 활동 (실생활 연결)

### 전개 (30분)
- 개념 설명 (10분): 시각 자료 활용, 단계적 설명
- 예제 풀이 (10분): 교사 주도 → 학생 참여
- 연습 문제 (10분): 개별/짝 활동

### 정리 (10분)
- 핵심 내용 요약
- 형성 평가 (간단한 퀴즈)
- 다음 수업 예고

## 대수 지도 시 유의점

### 변수 개념 도입
- 처음에는 □, △ 등 기호를 사용하여 미지수 개념 도입
- 점차 x, y 등의 문자로 전환
- "변수는 수를 담는 상자" 비유 활용

### 등식의 성질
- 양팔 저울 모형 활용하여 등식의 균형 개념 이해
- 양변에 같은 수를 더하거나 빼도 등식 성립
- 양변에 같은 수를 곱하거나 나눠도 등식 성립 (0 제외)

### 흔한 오개념과 대처법
1. **부호 오류**: -(-3) = -3으로 잘못 계산 → 수직선 활용
2. **분배법칙 오류**: 2(x+3) = 2x+3 → 넓이 모형으로 설명
3. **이항 시 부호**: x + 5 = 8에서 x = 8 + 5로 오류 → "반대로" 개념 강조

## 협력 학습 전략

### 짝 활동
- "가르치며 배우기": 한 학생이 다른 학생에게 풀이 설명
- 상호 검토: 서로의 풀이과정 확인

### 모둠 활동
- 4명 1조, 역할 분담 (문제 읽기, 식 세우기, 풀기, 검산)
- 갤러리 워크: 각 모둠의 풀이를 순회하며 평가

## 평가 방법

### 형성 평가
- 수업 중 즉석 퀴즈 (3-5문제, 5분)
- 출구 티켓 (수업 끝 1문제)
- 자기 평가 체크리스트

### 총괄 평가
- 단원 테스트: 개념 이해 50%, 문제 해결 30%, 서술형 20%
- 수행 평가: 실생활 프로젝트 포함

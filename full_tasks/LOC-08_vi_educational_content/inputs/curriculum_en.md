# Algebra Fundamentals Curriculum
## Grade 7-8 Mathematics

---

## Lesson 1: Introduction to Variables and Expressions

### Learning Objectives
- Understand the concept of a variable as a placeholder for unknown values
- Write algebraic expressions from word problems
- Evaluate expressions by substituting values

### Content
A **variable** is a letter (such as x, y, or n) that represents an unknown number. An **algebraic expression** combines variables, numbers, and operations.

**Examples:**
- "Five more than a number" → x + 5
- "Three times a number decreased by 2" → 3x - 2
- "The product of a number and itself" → x²

### Key Vocabulary
- Variable, constant, coefficient, term, expression

### Practice
Evaluate 3x + 7 when x = 4: 3(4) + 7 = 12 + 7 = 19

---

## Lesson 2: Combining Like Terms

### Learning Objectives
- Identify like terms in expressions
- Simplify expressions by combining like terms
- Apply the distributive property

### Content
**Like terms** have the same variable raised to the same power.
- 3x and 5x are like terms
- 2x² and 7x² are like terms
- 3x and 3x² are NOT like terms

**Simplification Rules:**
- 3x + 5x = 8x
- 4x² - 2x² = 2x²
- 2(x + 3) = 2x + 6 (distributive property)

---

## Lesson 3: Solving One-Step Equations

### Learning Objectives
- Solve equations using addition/subtraction
- Solve equations using multiplication/division
- Check solutions by substitution

### Content
An **equation** states that two expressions are equal. To solve, isolate the variable.

**Addition/Subtraction:**
- x + 5 = 12 → x = 12 - 5 = 7
- x - 3 = 8 → x = 8 + 3 = 11

**Multiplication/Division:**
- 3x = 15 → x = 15 ÷ 3 = 5
- x/4 = 6 → x = 6 × 4 = 24

---

## Lesson 4: Solving Two-Step Equations

### Learning Objectives
- Apply inverse operations in correct order
- Solve equations with two operations
- Translate word problems into two-step equations

### Content
For equations like 2x + 3 = 11:
1. Undo addition/subtraction first: 2x = 11 - 3 = 8
2. Undo multiplication/division: x = 8 ÷ 2 = 4

**More Examples:**
- 5x - 7 = 18 → 5x = 25 → x = 5
- x/3 + 4 = 10 → x/3 = 6 → x = 18

---

## Lesson 5: Solving Multi-Step Equations

### Learning Objectives
- Solve equations requiring multiple steps
- Handle variables on both sides
- Use distributive property in equation solving

### Content
**Variables on both sides:**
- 3x + 4 = x + 10
- 3x - x = 10 - 4
- 2x = 6, so x = 3

**With distributive property:**
- 2(x + 3) = 14
- 2x + 6 = 14
- 2x = 8, so x = 4

---

## Lesson 6: Introduction to Inequalities

### Learning Objectives
- Understand inequality symbols (<, >, ≤, ≥)
- Solve one-step inequalities
- Graph solutions on a number line

### Content
**Inequality symbols:**
- x > 3 means "x is greater than 3"
- x ≤ 5 means "x is less than or equal to 5"

**Solving:** Same as equations, BUT flip the sign when multiplying/dividing by negative.
- -2x > 6 → x < -3 (sign flipped!)

---

## Lesson 7: Linear Functions and Graphing

### Learning Objectives
- Understand the concept of a function
- Identify slope and y-intercept from y = mx + b
- Plot linear functions on a coordinate plane

### Content
A **linear function** has the form y = mx + b where:
- m = slope (rate of change)
- b = y-intercept (where line crosses y-axis)

**Example:** y = 2x + 1
- Slope = 2 (rise 2, run 1)
- Y-intercept = 1 (crosses at (0,1))

---

## Lesson 8: Systems of Equations (Introduction)

### Learning Objectives
- Understand what a system of equations represents
- Solve simple systems by substitution
- Interpret solutions graphically

### Content
A **system of equations** is two or more equations with the same variables.

**Example:**
- y = x + 2
- y = 3x - 4

Substitution: x + 2 = 3x - 4 → 6 = 2x → x = 3, y = 5

---

## Lesson 9: Polynomials and Basic Operations

### Learning Objectives
- Identify monomials, binomials, and polynomials
- Add and subtract polynomials
- Multiply monomials

### Content
- **Monomial:** single term (3x²)
- **Binomial:** two terms (x + 5)
- **Polynomial:** multiple terms (x² + 3x - 7)

**Addition:** (2x² + 3x) + (x² - 5x) = 3x² - 2x
**Multiplication:** (2x)(3x²) = 6x³

---

## Lesson 10: Word Problems and Real-World Applications

### Learning Objectives
- Translate real-world situations into algebraic models
- Solve application problems using learned techniques
- Verify reasonableness of answers

### Content
**Strategy for word problems:**
1. Read carefully and identify unknowns
2. Define variables
3. Write equation(s)
4. Solve
5. Check if answer makes sense

**Example:** A rectangle has perimeter 30 cm. Its length is twice its width. Find dimensions.
- Let w = width, then length = 2w
- 2(w + 2w) = 30 → 6w = 30 → w = 5
- Width = 5 cm, Length = 10 cm

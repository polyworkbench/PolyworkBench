# Rubric: MFG-07v2

## Dim 1: Bilingual Handover (30%)
- Excellent: Both ZH and VI versions complete and corresponding
- Good: Both present, minor gaps
- Adequate: One language complete

## Dim 2: Quality Integration (25%)
- Excellent: Quality metrics properly integrated in both handovers
- Good: Metrics present in one version
- Adequate: Some metrics mentioned

## Dim 3: Validation (25%)
- Excellent: Validation script run and passed
- Good: Script run with fixes applied
- Adequate: Attempted

## Dim 4: Content Accuracy (20%)
- Excellent: All numbers match source data
- Good: Most numbers correct
- Adequate: Some correct

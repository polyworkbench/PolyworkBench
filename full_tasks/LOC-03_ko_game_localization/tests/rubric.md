# Rubric: LOC-03

## Dimension 1: Dialogue Quality (Weight: 25%)
- **Excellent (9-10)**: Complete and accurate Korean dialogue translations maintaining meaning and tone from Japanese source
- **Good (7-8)**: Most dialogue translated with good quality
- **Adequate (5-6)**: Partial dialogue with some errors
- **Poor (1-4)**: Poor or missing translations
- **Zero (0)**: Not attempted or no relevant output

## Dimension 2: Cultural Adaptation (Weight: 25%)
- **Excellent (9-10)**: Proper cultural adaptation notes documenting changes from Japanese cultural context to Korean
- **Good (7-8)**: Good adaptation documentation
- **Adequate (5-6)**: Some adaptation notes
- **Poor (1-4)**: No cultural adaptation
- **Zero (0)**: Not attempted or no relevant output

## Dimension 3: Korean Naturalness (Weight: 20%)
- **Excellent (9-10)**: Natural Korean dialogue that sounds like native game writing (not translated Japanese)
- **Good (7-8)**: Good natural Korean with minor issues
- **Adequate (5-6)**: Understandable but clearly translated
- **Poor (1-4)**: Unnatural Korean
- **Zero (0)**: Not attempted or no relevant output

## Dimension 4: Character Consistency (Weight: 15%)
- **Excellent (9-10)**: Consistent character voices maintained throughout with voice guide documentation
- **Good (7-8)**: Good consistency with voice guide
- **Adequate (5-6)**: Some consistency issues
- **Poor (1-4)**: Inconsistent voices
- **Zero (0)**: Not attempted or no relevant output

## Dimension 5: Honorific Handling (Weight: 15%)
- **Excellent (9-10)**: Proper Japanese to Korean honorific mapping (敬語→존댓말/반말) appropriate to character relationships
- **Good (7-8)**: Good honorific handling with some mapping
- **Adequate (5-6)**: Basic honorific awareness
- **Poor (1-4)**: Honorifics ignored
- **Zero (0)**: Not attempted or no relevant output

## Language Quality Assessment
- Target language output must be professional quality in Korean
- No unwarranted English fallback (output must be in specified target language: Korean)
- Technical terminology must be domain-appropriate

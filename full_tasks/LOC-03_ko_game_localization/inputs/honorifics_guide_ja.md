# 日本語敬語体系ガイド — 星霜のアリア

## 概要

本作では、キャラクターの関係性と性格を表現するために、日本語の敬語・話し方の階層を活用しています。韓国語ローカライズ時には、これを韓国語の存待法（존대법）に適切にマッピングする必要があります。

## 敬語レベル分類

### 1. casual_male（タメ口・男性）
**使用キャラ:** アキラ、レン
- 一人称: 俺（おれ）
- 文末: だ、ぞ、ぜ、じゃない、か？
- 特徴: 男性的、カジュアル、友人間の会話

**アキラの場合:**
- 仲間に対して使用
- 真っ直ぐで正直な印象
- 怒り時: ～ねえ、～やがる

**レンの場合:**
- 全員に対して使用（目上にも）
- 攻撃的・見下した印象
- お前、てめえ を使用
- 普段より更に荒い（ぶっ殺す等）

### 2. polite_female（丁寧語・女性）
**使用キャラ:** ミヅキ
- 一人称: 私（わたし）
- 文末: です、ます、ですよ、ですね
- 相手の呼び方: ～さん
- 特徴: 丁寧、女性的、優しい印象
- 感情が高ぶった時: やや崩れるが基本は丁寧

### 3. polite_cheerful（丁寧語・元気）
**使用キャラ:** サクラ
- 一人称: 私（わたし）
- 文末: です！、ますよ！、ましょう！
- 特徴: 丁寧だが非常にエネルギッシュ
- 語尾を伸ばす: でーす、まーす
- 感情表現が大きい: わーっ！、えーっ！

### 4. archaic_royal（古語・王族）
**使用キャラ:** 皇帝ヴァルス
- 一人称: 私（わたくし）、この私
- 文末: ～せよ（命令）、～ぬ（否定）、～であろう
- 相手の呼び方: 貴様、者ども
- 特徴: 威厳、権力、古風な言い回し
- 全てにおいて上から目線

### 5. archaic_elderly（古語・老人）
**使用キャラ:** 老師カイン
- 一人称: ワシ
- 文末: じゃ、じゃよ、～おる、～よう
- 特徴: 老賢者の話し方、知恵を感じさせる
- 時折ユーモアを交える

### 6. royal_feminine（王族・女性）
**使用キャラ:** 女王エリス
- 一人称: 私（わたくし）
- 文末: ます、ください、たまえ（祝福時）
- 特徴: 品格と温かさの両立
- 臣下に対しても丁寧だが威厳あり

### 7. casual_merchant（商人口調）
**使用キャラ:** 商人ゴルド
- 一人称: アタシ、俺
- 文末: ぜ、わ、ますぜ
- 特徴: 商売人の親しみやすさ
- 丁寧語と乱暴語の混在
- 金に関する話題で特に生き生き

### 8. system（システム）
**使用:** ゲームシステムメッセージ
- 文末: ました、ますか？
- 特徴: 無感情、事実のみ
- 簡潔明瞭

## 韓国語マッピング推奨

| 日本語レベル | 韓国語推奨 |
|---|---|
| casual_male (アキラ) | 해체/반말 (나, ~다, ~거든) |
| rude_male (レン) | 반말 + 거친 표현 (너, ~거야, ~잖아) |
| polite_female (ミヅキ) | 해요체 (~해요, ~이에요) |
| polite_cheerful (サクラ) | 해요체 + 감탄사 많이 |
| archaic_royal (ヴァルス) | 하오체/하십시오체 혼합 (~하라, ~하도다) |
| archaic_elderly (カイン) | 해라체 + 고어 (~하느니라, ~지어다) |
| royal_feminine (エリス) | 하십시오체 (~하십시오, ~합니다) |
| casual_merchant (ゴルド) | 해요체 + 반말 혼합 |
| system | 합니다체 (격식체) |

# Rubric: MFG-13

## Dim 1: Capability Indices (35%)
- Excellent: Cp and Cpk within 5% of expected values (1.111, 0.844)
- Good: Within 10%
- Adequate: Within 20%
- Poor: Values present but wrong

## Dim 2: Assignable Causes (25%)
- Excellent: All 3 causes identified (shift change, tool wear, outlier)
- Good: 2 causes
- Adequate: 1 cause
- Poor: None identified

## Dim 3: German Report (20%)
- Excellent: Professional German with DMAIC structure
- Good: Acceptable German with most sections
- Adequate: Some German content
- Poor: English fallback

## Dim 4: Statistical Rigor (20%)
- Excellent: Correct formulas, control limits, proper methodology
- Good: Mostly correct
- Adequate: Basic calculations
- Poor: Major errors

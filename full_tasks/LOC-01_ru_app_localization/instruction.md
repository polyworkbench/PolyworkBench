# Локализация мобильного приложения на русский язык

## Задание

Вам необходимо локализовать строки интерфейса мобильного приложения TaskFlow с английского на русский язык. Используйте спецификацию функций на китайском языке для понимания контекста каждого экрана, а также руководство по стилю на русском языке.

## Исходные файлы

Все файлы находятся в `/workspace/inputs/`:

- `strings_en.json` — строки интерфейса на английском языке (ключи, максимальная длина, контекст)
- `feature_spec_zh.md` — спецификация функций на китайском языке с описанием каждого экрана
- `style_guide_ru.md` — руководство по стилю русской локализации с терминологией
- `pluralization_rules.json` — правила русского множественного числа и примеры

## Требования

- Перевести все строки на русский язык
- Соблюдать ограничения по длине (`max_length`) — минимум 80% строк должны укладываться в лимит
- Правильно обрабатывать русское множественное число (формы: 1, 2-4, 5+)
- Соблюдать терминологию из руководства по стилю (`style_guide_ru.md`)
- Учитывать контекст экранов из китайской спецификации
- Сохранять плейсхолдеры (например, `{count}`, `{name}`) без изменений
- Использовать обращение на «вы» (с маленькой буквы) согласно руководству по стилю
- Кнопки: инфинитив глагола (Сохранить, Удалить, Отменить)
- Заголовки: только первое слово с заглавной буквы

## Выходные файлы

Сохраните результаты в `/workspace/outputs/`:

- `strings_ru.json` — переведённые строки в формате JSON (ключ → перевод; для множественного числа — объект с формами one/few/many)
- `length_report.json` — отчёт о соответствии длине
- `context_notes_ru.md` — заметки переводчика по контексту
- `qa_checklist.json` — чек-лист проверки качества

## Формат strings_ru.json

```json
{
  "btn_save": "Сохранить",
  "plural_tasks": {
    "one": "{count} задача",
    "few": "{count} задачи",
    "many": "{count} задач"
  }
}
```

## Формат length_report.json

```json
{
  "total_strings": 100,
  "compliant": 85,
  "non_compliant": 15,
  "compliance_rate": 0.85,
  "details": [
    {
      "key": "btn_save",
      "original_length": 4,
      "translated_length": 9,
      "max_length": 12,
      "status": "pass"
    }
  ]
}
```

## Формат qa_checklist.json

```json
{
  "checks": [
    {"category": "terminology", "description": "...", "status": "pass|fail", "notes": "..."},
    {"category": "pluralization", "description": "...", "status": "pass|fail", "notes": "..."}
  ]
}
```

**Важно: Все продукты должны быть записаны в файлы на диск, не просто выводите текст. Используйте bash-команды для создания директорий, записи файлов и выполнения скриптов.**

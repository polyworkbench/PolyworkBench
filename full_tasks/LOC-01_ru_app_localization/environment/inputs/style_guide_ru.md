# Руководство по стилю — Русская локализация TaskFlow

## 1. Общие принципы

### Обращение к пользователю
- Используйте **«вы»** (с маленькой буквы) для обращения к пользователю
- Тон: дружелюбный, но профессиональный
- Избегайте канцеляризмов и сложных конструкций

### Длина строк
- Русский текст в среднем на 30–40% длиннее английского
- При превышении лимита используйте сокращения или переформулировки
- Приоритет: точность > краткость, но длина не должна ломать UI

### Регистр
- Заголовки экранов: только первое слово с заглавной буквы
- Кнопки: первое слово с заглавной буквы
- Не используйте ALL CAPS

## 3. Кнопки

- Используйте инфинитив глагола: «Сохранить», «Удалить», «Отменить»
- Короткие и ясные: «Далее», «Назад», «Готово»
- «Повторить» вместо «Попробовать снова» (для экономии места)

## 4. Сообщения об ошибках

- Начинайте с описания проблемы
- Предлагайте решение, если возможно
- Пример: «Нет подключения к интернету. Проверьте соединение.»
- Не используйте восклицательные знаки

## 5. Множественное число

Русский язык имеет три формы числительных:
- **one** (1, 21, 31...): задача, минута, час, день
- **few** (2–4, 22–24...): задачи, минуты, часа, дня
- **many** (5–20, 25–30...): задач, минут, часов, дней

Формат: `{count} задача` / `{count} задачи` / `{count} задач`

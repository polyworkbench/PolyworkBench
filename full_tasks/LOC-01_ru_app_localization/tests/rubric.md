# Rubric: LOC-01

## Dimension 1: Translation Coverage (Weight: 30%)
- **Excellent (9-10)**: All source strings translated to Russian with no missing entries
- **Good (7-8)**: 90%+ strings translated with minor gaps
- **Adequate (5-6)**: 50-89% strings translated
- **Poor (1-4)**: Less than 50% translated
- **Zero (0)**: Not attempted or no relevant output

## Dimension 2: Length Compliance (Weight: 25%)
- **Excellent (9-10)**: All translations fit within UI character limits with no truncation issues
- **Good (7-8)**: 90%+ strings within limits
- **Adequate (5-6)**: 70-89% within limits
- **Poor (1-4)**: Major length violations throughout
- **Zero (0)**: Not attempted or no relevant output

## Dimension 3: Russian Quality (Weight: 20%)
- **Excellent (9-10)**: Natural Russian UI language with proper localization conventions, no calques or awkward phrasing
- **Good (7-8)**: Good Russian with minor unnatural phrasing
- **Adequate (5-6)**: Understandable but unnatural Russian
- **Poor (1-4)**: Poor Russian or English fallback
- **Zero (0)**: Not attempted or no relevant output

## Dimension 4: Consistency (Weight: 15%)
- **Excellent (9-10)**: Consistent terminology throughout (same term for same concept, matching tone/formality)
- **Good (7-8)**: Good consistency with minor variations
- **Adequate (5-6)**: Some inconsistencies in terminology
- **Poor (1-4)**: Major inconsistencies
- **Zero (0)**: Not attempted or no relevant output

## Dimension 5: Context Accuracy (Weight: 10%)
- **Excellent (9-10)**: Context notes accurately describe UI placement and guide translation choices
- **Good (7-8)**: Good context documentation
- **Adequate (5-6)**: Basic context notes
- **Poor (1-4)**: No context notes
- **Zero (0)**: Not attempted or no relevant output

## Language Quality Assessment
- Target language output must be professional quality in Russian
- No unwarranted English fallback (output must be in specified target language: Russian)
- Technical terminology must be domain-appropriate

# Rubric: COM-09

## Dimension 1: Compliance Accuracy (Weight: 30%)
- **Excellent (9-10)**: Compliance matrix in Korean covering all 3 frameworks (FDA, GB, JIS), 4+ products referenced (PROD-XXX), compliance status categories, substantial content
- **Good (7-8)**: Matrix with all frameworks and some product/status references
- **Adequate (5-6)**: Partial framework coverage or missing product references
- **Poor (1-4)**: Minimal compliance matrix
- **Zero (0)**: No compliance matrix

## Dimension 2: Gap Detection (Weight: 25%)
- **Excellent (9-10)**: Korean gap analysis with regulatory references (FDA-XX, GB-XX, JIS-XX), critical gaps identified, conflicting requirements detected
- **Good (7-8)**: Gap analysis with some regulatory references and gap indicators
- **Adequate (5-6)**: Basic gap identification without specific references
- **Poor (1-4)**: Minimal gap content
- **Zero (0)**: No gap analysis

## Dimension 3: Korean Output (Weight: 20%)
- **Excellent (9-10)**: Korean content (>35% Hangul ratio) consistently across all outputs (report, matrix, actions), 3+ structured sections, 2000+ chars
- **Good (7-8)**: Korean in most outputs with some structure
- **Adequate (5-6)**: Korean present but inconsistent across outputs
- **Poor (1-4)**: Minimal Korean content
- **Zero (0)**: No Korean content

## Dimension 4: Action Items (Weight: 15%)
- **Excellent (9-10)**: Structured Korean action items with priority levels and cost/timeline estimates
- **Good (7-8)**: Action items with Korean content and priority or timeline
- **Adequate (5-6)**: Basic action items without prioritization
- **Poor (1-4)**: Minimal action content
- **Zero (0)**: No action items

## Dimension 5: Regulatory Mapping (Weight: 10%)
- **Excellent (9-10)**: Summary mapping all 3 frameworks with 8+ requirement IDs and substantial cross-reference content
- **Good (7-8)**: Mapping with all frameworks and some requirement IDs
- **Adequate (5-6)**: Basic mapping with limited detail
- **Poor (1-4)**: Minimal regulatory summary
- **Zero (0)**: No regulatory mapping

## Language Quality Assessment
- Target language output must be professional quality Korean
- No English fallback in Korean-designated outputs
- Technical terminology must be domain-appropriate for regulatory compliance

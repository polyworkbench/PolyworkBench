BENCHMARKS DES PRIX MARCHÉ FRANÇAIS - T4 2024
Source : Étude de marché interne + données GfK/Euromonitor
Mise à jour : Octobre 2024

=== CATÉGORIE : AUDIO SANS FIL (Écouteurs TWS) ===
Segment milieu de gamme (15-40 EUR prix d'achat grossiste) :
- Prix moyen d'achat grossiste : 22,50 EUR HT
- Prix public moyen constaté : 49,90 EUR TTC
- Marge distributeur moyenne : 45-55%
- Leaders : JBL, Samsung, Xiaomi, Nothing
- Tendance : forte pression baissière (-8% vs N-1)
- Volume marché France : 4,2 millions d'unités/an

Segment premium (40-80 EUR prix d'achat grossiste) :
- Prix moyen d'achat grossiste : 55,00 EUR HT
- Prix public moyen constaté : 129,00 EUR TTC
- Leaders : Apple, Sony, Bose, Sennheiser

=== CATÉGORIE : ACCESSOIRES SOIE ===
Foulards/écharpes soie haut de gamme :
- Prix moyen d'achat grossiste : 28,00 EUR HT
- Prix public moyen constaté : 75,00 - 120,00 EUR TTC
- Marge distributeur : 60-70%
- Concurrence : marques françaises artisanales (45-60 EUR achat)
- Tendance : croissance modérée (+3% vs N-1)
- Point de vigilance : perception qualité produits chinois vs français/italien

=== CATÉGORIE : ARTICLES MÉNAGERS INOX ===

=== CATÉGORIE : ARTS DE LA TABLE / PORCELAINE ===
Services de table porcelaine 24 pièces :

- Marge distributeur : 50-60%

=== CATÉGORIE : THÉ BIO IMPORTÉ ===
Thé vert bio premium (conditionnement 100g) :
- Prix moyen d'achat grossiste : 9,50 EUR HT / 100g
- Prix public moyen constaté : 18,00 - 28,00 EUR TTC / 100g
- Marge distributeur : 45-55%
- Réseaux : Palais des Thés, Mariage Frères, bio spécialisé
- Tendance : croissance forte segment bio (+12% vs N-1)
- Point de vigilance : certification bio EU obligatoire, contrôles pesticides renforcés

=== CATÉGORIE : COSMÉTIQUES / SOINS VISAGE ===
Sérums hydratants acide hyaluronique 30ml :
- Prix moyen d'achat grossiste : 5,20 EUR HT
- Prix public moyen constaté : 15,00 - 30,00 EUR TTC
- Marge distributeur : 60-70%
- Leaders : The Ordinary, La Roche-Posay, CeraVe
- Tendance : forte croissance (+15% skincare)

=== CATÉGORIE : CHAUSSURES DE SPORT ===
Running / training segment milieu de gamme :

# Rubric: KNW-05

## Dimension 1: Vietnamese Manual Quality (Weight: 25%)
- **Excellent (9-10)**: Comprehensive training manual in Vietnamese with proper diacritics, 5+ chapters, learning objectives, professional pedagogical structure
- **Good (7-8)**: Good Vietnamese manual with structure and objectives
- **Adequate (5-6)**: Basic Vietnamese manual present
- **Poor (1-4)**: Minimal manual content
- **Zero (0)**: No training manual

## Dimension 2: Exercise Quality (Weight: 20%)
- **Excellent (9-10)**: Vietnamese exercises with variety (2+ difficulty levels), 10+ exercises, proper Vietnamese content and instructions
- **Good (7-8)**: Exercises with difficulty levels and Vietnamese content
- **Adequate (5-6)**: Basic exercises present
- **Poor (1-4)**: Minimal exercises
- **Zero (0)**: No exercises

## Dimension 3: Glossary Accuracy (Weight: 15%)
- **Excellent (9-10)**: Trilingual glossary (Vietnamese, English, Chinese) with 40+ terms, key cloud computing terms covered, Vietnamese definitions present
- **Good (7-8)**: 25+ trilingual terms with Vietnamese definitions
- **Adequate (5-6)**: 15+ terms with some languages
- **Poor (1-4)**: Minimal glossary
- **Zero (0)**: No glossary

## Dimension 4: Pedagogical Structure (Weight: 15%)
- **Excellent (9-10)**: Clear learning progression, 20+ assessment questions with type variety (3+ types), chapter summaries, covered objectives in answer
- **Good (7-8)**: Assessment questions with some variety and chapter summaries
- **Adequate (5-6)**: Basic pedagogical elements
- **Poor (1-4)**: Minimal structure
- **Zero (0)**: No pedagogical structure

## Dimension 5: Completeness (Weight: 25%)
- **Excellent (9-10)**: All files present (manual, exercises, glossary, assessment questions), answer.json with total_chapters (5+) and covered_objectives
- **Good (7-8)**: Most files present with answer data
- **Adequate (5-6)**: Some files missing
- **Poor (1-4)**: Major gaps
- **Zero (0)**: No output

## Language Quality Assessment
- Target language output must be professional quality Vietnamese
- No English fallback in training manual and exercises
- Technical terminology must be domain-appropriate for cloud computing education

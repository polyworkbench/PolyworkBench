# 云计算服务技术文档

## AWS与阿里云核心服务对比

### 1. 计算服务

#### AWS EC2（弹性计算云）
AWS EC2提供可调整的计算容量，支持多种实例类型满足不同工作负载需求。最新一代实例包括：
- **通用型（M7i）**：平衡的计算、内存和网络资源，适用于Web服务器和应用服务器
- **计算优化型（C7g）**：基于Graviton3处理器，适合批处理、科学建模和游戏服务器
- **内存优化型（R7i）**：大内存容量，适合内存数据库和实时大数据分析
- **存储优化型（I4i）**：高顺序读写和低延迟IOPS，适合数据仓库和分布式文件系统

自动伸缩组（Auto Scaling Group）可根据CPU利用率、网络流量等指标自动调整实例数量。

#### 阿里云ECS（弹性计算服务）
阿里云ECS提供安全可靠的弹性计算服务，核心优势包括：
- **弹性裸金属服务器（神龙）**：兼具虚拟机弹性和物理机性能，无虚拟化开销
- **抢占式实例**：相比按量付费实例最高节省90%成本
- **专有宿主机（DDH）**：满足合规性要求的独占物理服务器
- **GPU实例（gn7i系列）**：搭载NVIDIA A100/A10显卡，适用于AI推理和训练

弹性伸缩服务（ESS）支持定时伸缩、动态伸缩和自定义伸缩策略。

### 2. 存储服务

#### 对象存储对比
| 特性 | AWS S3 | 阿里云OSS |
|------|--------|-----------|
| 持久性 | 99.999999999%（11个9） | 99.9999999999%（12个9） |
| 可用性SLA | 99.99% | 99.995% |
| 存储类别 | 标准、智能分层、IA、Glacier | 标准、低频、归档、冷归档 |
| 最大对象大小 | 5 TB | 48.8 TB |
| 生命周期管理 | 支持 | 支持 |
| 跨区域复制 | 支持 | 支持 |

#### 块存储
- **AWS EBS**：gp3（通用SSD）提供3000 IOPS基准，io2 Block Express最高可达256000 IOPS
- **阿里云ESSD**：PL0/PL1/PL2/PL3四个性能等级，PL3提供最高100万IOPS

### 3. 数据库服务

#### 关系型数据库
- **AWS RDS**：支持MySQL、PostgreSQL、Oracle、SQL Server、MariaDB，以及自研Aurora
- **阿里云RDS**：支持MySQL、PostgreSQL、SQL Server、MariaDB，以及自研PolarDB

**PolarDB关键特性**：
- 计算与存储分离架构
- 最大支持128TB存储容量
- 读写分离，最多支持15个只读节点
- 秒级弹性扩容
- 兼容MySQL、PostgreSQL和Oracle语法

#### NoSQL数据库
- **AWS DynamoDB**：完全托管的键值和文档数据库，单位毫秒延迟
- **阿里云Tablestore**：多模型NoSQL数据库，支持宽表和时序数据

### 4. 网络与安全

#### VPC网络架构
两个平台均提供虚拟私有云（VPC），支持：
- 子网划分（公有子网/私有子网）
- 路由表配置
- 网络ACL和安全组
- VPN网关和专线连接

#### 安全服务对比
| 服务类型 | AWS | 阿里云 |
|---------|-----|--------|
| 身份管理 | IAM | RAM（资源访问管理） |
| 密钥管理 | KMS | KMS |
| Web应用防火墙 | WAF | WAF |
| DDoS防护 | Shield | DDoS防护 |
| 安全审计 | CloudTrail | 操作审计 |
| 威胁检测 | GuardDuty | 云安全中心 |

### 5. 无服务器计算

#### AWS Lambda
- 支持运行时：Node.js、Python、Java、Go、.NET、Ruby
- 最大执行时间：15分钟
- 内存配置：128MB-10240MB
- 并发限制：默认1000，可申请提升
- 定价：$0.20/百万次请求 + $0.0000166667/GB-秒

#### 阿里云函数计算（FC）
- 支持运行时：Node.js、Python、Java、Go、PHP、.NET、Custom Runtime
- 最大执行时间：86400秒（24小时，异步调用）
- 内存配置：128MB-32768MB
- GPU实例支持（AI推理场景）
- 定价：按调用次数+执行时间+网络流量计费

### 6. 容器服务

#### 容器编排平台
- **AWS EKS**：托管Kubernetes服务，Fargate支持无服务器容器
- **阿里云ACK**：容器服务Kubernetes版，支持Serverless版（ASK）

#### 容器镜像服务
- **AWS ECR**：完全托管的Docker容器注册表
- **阿里云ACR**：容器镜像服务，支持企业版多地域同步

### 7. 大数据与AI服务

#### 数据分析
- **AWS**：Redshift（数据仓库）、EMR（Hadoop/Spark）、Athena（无服务器查询）
- **阿里云**：MaxCompute（大数据计算）、DataWorks（数据开发平台）、Hologres（实时分析）

#### 机器学习平台
- **AWS SageMaker**：端到端ML平台，支持训练、调优和部署
- **阿里云PAI**：机器学习平台，包含PAI-Studio（可视化建模）、PAI-DSW（Notebook开发）、PAI-EAS（在线推理）

# 엣지 AI 기술 평가 보고서 작성

## 과제 배경

영문 기술 백서(edge AI inference 관련)와 일본어 연구 노트(모델 압축 기술)를 종합하여 한국어 기술 평가 보고서를 작성하십시오.

## 입력 파일

모든 입력 파일은 `/workspace/inputs/` 디렉토리에 있습니다:

- `whitepaper_en.md`: 엣지 AI 추론에 관한 영문 기술 백서 (~1500단어)
- `research_notes_ja.md`: 모델 압축에 관한 일본어 연구 노트
- `benchmark_data_en.csv`: 성능 벤치마크 데이터 (지연시간, 정확도, 전력소비)
- `market_data_ja.json`: 일본 엣지 디바이스 시장 데이터

## 출력 요구사항

아래 파일들을 `/workspace/output/` 디렉토리에 생성하십시오:

### 1. `tech_assessment_ko.md`
- 한국어로 작성된 기술 평가 보고서
- 다음 섹션을 포함할 것:
  - 기술 개요 (엣지 AI 추론의 현황)
  - 핵심 기술 분석 (모델 압축, 경량화, 하드웨어 최적화)
  - 성능 벤치마크 분석 결과
  - 시장 동향 및 전망
  - 결론 및 시사점
- 최소 2000자 이상
- 전문 기술 용어는 한국어로 번역하되, 필요시 영문 병기

### 2. `comparison_matrix.json`
- 엣지 AI 솔루션 비교 매트릭스
- 각 솔루션에 대해: 이름, 방법론, 지연시간, 정확도, 전력소비, 적용 분야
- 최소 5개 솔루션 비교

### 3. `feasibility_ko.json`
- 기술 실현 가능성 분석
- 평가 항목: 기술 성숙도, 비용 효율성, 확장성, 시장 준비도
- 각 항목에 대한 점수(1-5)와 한국어 근거 설명

### 4. `recommendations_ko.md`
- 한국어로 작성된 기술 도입 권고사항
- 단기/중기/장기 전략 구분
- 각 권고사항에 대한 근거와 예상 효과
- 리스크 요인 분석 포함
- 최소 800자 이상

### 5. `/workspace/answer.json`
- 포함 필드:
  - `top_recommendation`: 최우선 권고사항 (한국어)
  - `feasibility_score`: 전체 실현 가능성 점수 (1-5)
  - `key_technologies`: 핵심 기술 목록
  - `market_size_estimate`: 시장 규모 추정치

## 평가 기준

- **종합 품질 (25%)**: 영문 백서와 일본어 노트의 효과적 통합
- **한국어 기술문서 품질 (25%)**: 전문 기술 용어의 적절한 한국어 표현
- **비교 분석 정확도 (20%)**: 벤치마크 데이터의 정확한 반영
- **실현 가능성 분석 (15%)**: 논리적이고 체계적인 분석
- **권고사항 (15%)**: 실행 가능하고 구체적인 제안

**중요: 모든 산출물은 반드시 디스크 파일로 저장해야 합니다. 텍스트로만 응답하지 마십시오. bash 명령어를 사용하여 디렉토리 생성, 파일 작성, 스크립트 실행을 수행하십시오.**

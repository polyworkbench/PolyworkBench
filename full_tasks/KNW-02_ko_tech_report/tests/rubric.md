# Rubric: KNW-02

## Dimension 1: Synthesis Quality (Weight: 25%)
- **Excellent (9-10)**: Technical assessment synthesizing multiple sources with comprehensive analysis, clear methodology, 2000+ chars
- **Good (7-8)**: Good synthesis with most sources integrated
- **Adequate (5-6)**: Basic synthesis
- **Poor (1-4)**: Minimal synthesis
- **Zero (0)**: No assessment report

## Dimension 2: Korean Technical (Weight: 25%)
- **Excellent (9-10)**: Professional Korean technical writing with domain-specific terminology, proper formal register, rich Hangul content
- **Good (7-8)**: Good Korean technical content
- **Adequate (5-6)**: Some Korean technical writing
- **Poor (1-4)**: Minimal Korean
- **Zero (0)**: No Korean content

## Dimension 3: Comparison Accuracy (Weight: 20%)
- **Excellent (9-10)**: Comparison matrix with technologies evaluated on consistent criteria, Korean explanations, quantitative data
- **Good (7-8)**: Matrix with most technologies and Korean content
- **Adequate (5-6)**: Basic comparison present
- **Poor (1-4)**: Minimal comparison data
- **Zero (0)**: No comparison matrix

## Dimension 4: Feasibility (Weight: 15%)
- **Excellent (9-10)**: Feasibility assessment in Korean with structured evaluation criteria, practical constraints, and implementation considerations
- **Good (7-8)**: Feasibility with Korean content and some criteria
- **Adequate (5-6)**: Basic feasibility data
- **Poor (1-4)**: Minimal feasibility
- **Zero (0)**: No feasibility assessment

## Dimension 5: Recommendations (Weight: 15%)
- **Excellent (9-10)**: Korean recommendations with time horizons (short/mid/long term), risk analysis, 800+ Korean chars, top recommendation and feasibility score in answer
- **Good (7-8)**: Recommendations with time phases and some risk analysis
- **Adequate (5-6)**: Basic recommendations
- **Poor (1-4)**: Minimal recommendations
- **Zero (0)**: No recommendations

## Language Quality Assessment
- Target language output must be professional quality Korean
- No English fallback in technical assessment and recommendations
- Technical terminology must be domain-appropriate for technology evaluation

# Rubric: MFG-12

## Dim 1: Cluster Accuracy (35%)
- Excellent: 5 clusters correctly identified with correct alert assignments
- Good: 4 clusters correct
- Adequate: 3 clusters correct
- Poor: 1-2 clusters

## Dim 2: False Alarm Detection (25%)
- Excellent: All 4 false alarms (sensor drift) correctly identified
- Good: 3 false alarms found
- Adequate: 2 found
- Poor: 1 or none

## Dim 3: Ticket Correlation (20%)
- Excellent: 3 tickets correctly linked to clusters
- Good: 2 linked
- Adequate: 1 linked

## Dim 4: Multilingual Parsing (20%)
- Excellent: All 3 source languages correctly parsed
- Good: 2 languages
- Adequate: 1 language

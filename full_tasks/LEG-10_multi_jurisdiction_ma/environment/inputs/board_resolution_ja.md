## 第1号議案：中国子会社（北京華数智能科技有限公司）の完全子会社化について

### 議案の趣旨

当社は、中国子会社である北京華数智能科技有限公司（以下「対象会社」）の少数株主持分（40%）を取得し、完全子会社化することを提案する。

### 取得概要

| 項目 | 内容 |
|------|------|
| 対象会社 | 北京華数智能科技有限公司 |
| 所在地 | 中華人民共和国 北京市海淀区中関村ソフトウェアパーク |
| 事業内容 | エンタープライズソフトウェア開発、クラウドサービス、データ分析 |
| 現在の持株比率 | 60%（当社保有） |
| 取得対象 | 残り40%の株式 |
| **取得価格** | **5,000万米ドル（USD 50,000,000）** |
| 支払方法 | 現金（銀行借入による資金調達） |
| 想定完了日 | 2024年9月30日 |

### 取得価格の根拠

- 対象会社の企業価値評価（DCF法）：1億1,500万〜1億3,000万米ドル
- 40%持分の理論値：4,600万〜5,200万米ドル
- コントロールプレミアム（10%）を考慮
- 独立した第三者評価機関（デロイト・トウシュ・トーマツ）による評価書に基づく

### 条件先行事項

1. 中国商務部（MOFCOM）による対外投資審査の承認
2. 中国国家市場監督管理総局（SAMR）による独占禁止審査
3. 韓国公正取引委員会への企業結合届出（韓国での売上が届出基準を超過するため）
4. 対象会社のデータセキュリティ審査（中国サイバーセキュリティ法に基づく）
5. 既存株主の売却同意
6. 資金調達の完了

### 議決

全員一致で本議案を承認する。

代表取締役社長 田中太郎に対し、本取引に関する一切の契約締結権限を委任する。

## 第3号議案：取締役 Alexander Petrov 氏の利益相反について

取締役 Alexander Petrov 氏は、ロシア連邦国籍を有し、過去にロシア国営企業 Rostec Corporation の子会社に勤務していた経歴がある。本件取引に関し、Alexander Petrov 氏が EU/米国の制裁リストの対象となる可能性について、外部法律事務所（アレン・アンド・オーヴァリー）に確認を依頼済み。

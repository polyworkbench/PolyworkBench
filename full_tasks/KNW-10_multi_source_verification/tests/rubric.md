# Rubric: KNW-10

## Dimension 1: Claim Verification (Weight: 30%)
- **Excellent (9-10)**: All claims verified against multiple sources, correct verdicts (verified/refuted/unverifiable) assigned, evidence cited for each determination
- **Good (7-8)**: Most claims verified with evidence
- **Adequate (5-6)**: Some claims checked
- **Poor (1-4)**: Minimal verification
- **Zero (0)**: No verification

## Dimension 2: Source Cross-Referencing (Weight: 25%)
- **Excellent (9-10)**: Multiple language sources cross-referenced, contradictions identified and resolved, source reliability assessed
- **Good (7-8)**: Good cross-referencing with some contradiction resolution
- **Adequate (5-6)**: Basic cross-referencing
- **Poor (1-4)**: Minimal cross-referencing
- **Zero (0)**: No cross-referencing

## Dimension 3: Confidence Calibration (Weight: 15%)
- **Excellent (9-10)**: Well-calibrated confidence scores (verified claims higher), calibration reflects actual evidence strength
- **Good (7-8)**: Generally appropriate confidence levels
- **Adequate (5-6)**: Confidence scores present but poorly calibrated
- **Poor (1-4)**: Random or uniform confidence
- **Zero (0)**: No confidence data

## Dimension 4: Report Quality (Weight: 20%)
- **Excellent (9-10)**: Verification report (1000+ words) with 3+ structured sections, claim references, clear methodology
- **Good (7-8)**: Good report with structure (500+ words)
- **Adequate (5-6)**: Basic report (200+ words)
- **Poor (1-4)**: Minimal report
- **Zero (0)**: No report

## Dimension 5: Completeness (Weight: 10%)
- **Excellent (9-10)**: All deliverables present (fact sheet, citations, confidence data, report), answer.json complete
- **Good (7-8)**: Most deliverables present
- **Adequate (5-6)**: Some files missing
- **Poor (1-4)**: Major gaps
- **Zero (0)**: No output

## Language Quality Assessment
- Target language output must be professional quality English
- Source language handling must be accurate (no mistranslation from multilingual sources)
- Technical terminology must be domain-appropriate for fact verification

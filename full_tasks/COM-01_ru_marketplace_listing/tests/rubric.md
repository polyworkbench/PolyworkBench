# Rubric: COM-01

## Dimension 1: Listings Quality (Weight: 35%)
- **Excellent (9-10)**: All 20 products translated to Russian with complete fields (title, description, category, price_rub, sku, material, weight), natural Russian language, and RUB pricing in 500-50000 range
- **Good (7-8)**: 15+ products with most fields complete, primarily Russian text, reasonable pricing
- **Adequate (5-6)**: 10+ products with partial fields, some Russian content, some pricing issues
- **Poor (1-4)**: Few products, missing fields, minimal Russian, or unreasonable pricing
- **Zero (0)**: No listings produced

## Dimension 2: SEO Keywords (Weight: 20%)
- **Excellent (9-10)**: Russian-language SEO keywords covering all products with 3+ keywords each, market-appropriate terminology
- **Good (7-8)**: Keywords in Russian for most products, adequate coverage
- **Adequate (5-6)**: Some Russian keywords present but incomplete coverage
- **Poor (1-4)**: Few or non-Russian keywords
- **Zero (0)**: No SEO keywords generated

## Dimension 3: Size Conversion (Weight: 15%)
- **Excellent (9-10)**: Complete CN→RU size conversion table with standard size values (40-48), proper mapping between systems
- **Good (7-8)**: Size table present with both CN and RU references and numeric values
- **Adequate (5-6)**: Size table exists but missing one system or incomplete values
- **Poor (1-4)**: Minimal or incorrect size conversion data
- **Zero (0)**: No size conversion table

## Dimension 4: Compliance Tags (Weight: 20%)
- **Excellent (9-10)**: Compliance tags reference TR TS regulations, EAC marking, and specific regulation numbers (017, 004, 021)
- **Good (7-8)**: References TR TS and EAC with some regulation specifics
- **Adequate (5-6)**: Basic compliance awareness but missing specific references
- **Poor (1-4)**: Minimal compliance information
- **Zero (0)**: No compliance tags

## Dimension 5: Validation Script (Weight: 10%)
- **Excellent (9-10)**: Working Python validation script that checks listing quality
- **Good (7-8)**: Script exists with basic validation logic
- **Adequate (5-6)**: Script exists but minimal functionality
- **Poor (1-4)**: Script present but non-functional
- **Zero (0)**: No validation script

## Language Quality Assessment
- Target language output must be professional quality Russian
- No English fallback in customer-facing content
- Technical terminology must follow Russian e-commerce conventions

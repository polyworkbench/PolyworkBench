# Адаптация каталога товаров для маркетплейса Ozon

В `/workspace/inputs/` находятся файлы каталога китайского поставщика и рекомендации по бренду на английском языке. Необходимо адаптировать 20 товарных карточек для российского маркетплейса Ozon.

Требования:
- Перевести и адаптировать названия и описания товаров на русский язык (не дословный перевод, а маркетинговая адаптация)
- Сгенерировать SEO-ключевые слова для каждого товара (5–8 ключей на русском)
- Конвертировать размеры (CN → RU) и создать таблицу соответствия размеров
- Добавить теги соответствия российским стандартам (ТР ТС, EAC маркировка)
- Создать Python-скрипт для валидации полноты карточек (все обязательные поля Ozon)
- Рассчитать рекомендованные розничные цены в рублях (с учётом курса из входных данных)

Результаты сохранить в `/workspace/output/`, финальную сводку в `/workspace/answer.json`.

**重要：所有产出必须写入磁盘文件，不要只回复文本。用 bash 命令创建目录、写文件、执行脚本。**

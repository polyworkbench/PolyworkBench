# Сравнительный анализ логистических маршрутов

## Описание задачи

Проведите сравнительный анализ маршрутов доставки Китай→Россия и Китай→Вьетнам. Рассчитайте соотношение стоимости и времени доставки, создайте калькулятор расчёта стоимости и подготовьте аналитический отчёт на русском языке с рекомендациями.

## Входные файлы

- `/workspace/inputs/routes_china_russia_zh.csv` — данные китайских логистических провайдеров для маршрутов в Россию (на китайском языке)
- `/workspace/inputs/routes_china_vietnam_vi.csv` — данные вьетнамских логистических провайдеров (на вьетнамском языке)
- `/workspace/inputs/carrier_rates_en.json` — тарифы международных перевозчиков (на английском)
- `/workspace/inputs/customs_timeline_en.md` — сроки таможенного оформления (на английском)

## Требования

- Извлечь и систематизировать данные о маршрутах из всех источников (китайский, вьетнамский, английский)
- Рассчитать полную стоимость доставки для каждого маршрута (перевозка + таможня + последняя миля)
- Сравнить сроки доставки с учётом таможенного оформления
- Создать Python-скрипт калькулятора стоимости с параметрами: вес, объём, тип товара, маршрут
- Определить оптимальные маршруты для различных категорий товаров
- Подготовить рекомендации на русском языке в формате JSON
- Написать подробный аналитический отчёт на русском языке в формате Markdown

## Выходные файлы

Сохраните в `/workspace/output/`:

1. `logistics_comparison_ru.md` — аналитический отчёт на русском языке
2. `route_analysis.json` — структурированный анализ маршрутов
3. `cost_calculator.py` — скрипт калькулятора стоимости доставки
4. `recommendations_ru.json` — рекомендации (на русском)

Также создайте `/workspace/answer.json`:
```json
{
  "total_routes_analyzed": <int>,
  "cheapest_route_russia": "<route_name>",
  "fastest_route_russia": "<route_name>",
  "cheapest_route_vietnam": "<route_name>",
  "fastest_route_vietnam": "<route_name>",
  "avg_cost_difference_pct": <float>,
  "avg_time_difference_days": <float>,
  "recommended_route_electronics": "<route_name>"
}
```

**重要：所有产出必须写入磁盘文件，不要只回复文本。用 bash 命令创建目录、写文件、执行脚本。**

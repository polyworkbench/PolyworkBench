# Rubric: COM-08

## Dimension 1: Route Comparison (Weight: 25%)
- **Excellent (9-10)**: Complete route analysis covering both Russia and Vietnam destinations, 3+ transport modes (air, rail, sea), with cost and transit time data
- **Good (7-8)**: Both destinations with multiple modes and some cost/time data
- **Adequate (5-6)**: One destination or limited mode coverage
- **Poor (1-4)**: Minimal route information
- **Zero (0)**: No route analysis

## Dimension 2: Cost Calculations (Weight: 25%)
- **Excellent (9-10)**: Cheapest and fastest routes identified for both Russia and Vietnam, with average cost difference percentage and time difference in days
- **Good (7-8)**: Most route identifications with comparative metrics
- **Adequate (5-6)**: Some route identification without full comparisons
- **Poor (1-4)**: Minimal cost data
- **Zero (0)**: No cost calculations

## Dimension 3: Russian Report (Weight: 20%)
- **Excellent (9-10)**: Russian logistics report (>40% Cyrillic), 3+ markdown sections, 2000+ chars, professional logistics terminology
- **Good (7-8)**: Russian report with structure and adequate length
- **Adequate (5-6)**: Some Russian content but limited structure
- **Poor (1-4)**: Minimal Russian content
- **Zero (0)**: No Russian report

## Dimension 4: Script Quality (Weight: 15%)
- **Excellent (9-10)**: Valid Python cost calculator with parameterization (weight, volume, route, mode), calculation logic, and defined functions
- **Good (7-8)**: Valid script with parameters and calculations
- **Adequate (5-6)**: Script exists but limited functionality
- **Poor (1-4)**: Script with errors
- **Zero (0)**: No script

## Dimension 5: Recommendations (Weight: 15%)
- **Excellent (9-10)**: Structured Russian recommendations with actionable content and optimization suggestions
- **Good (7-8)**: Russian recommendations with some structure
- **Adequate (5-6)**: Basic recommendations present
- **Poor (1-4)**: Minimal recommendation content
- **Zero (0)**: No recommendations

## Language Quality Assessment
- Target language output must be professional quality Russian
- No English fallback in the logistics report and recommendations
- Technical terminology must be domain-appropriate for logistics/supply chain

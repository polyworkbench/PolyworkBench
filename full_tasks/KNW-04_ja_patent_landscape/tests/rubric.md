# Rubric: KNW-04

## Dimension 1: Patent Landscape Coverage (Weight: 25%)
- **Excellent (9-10)**: Comprehensive landscape report in Japanese covering multiple technology areas, filing trends, key applicants, with geographic analysis
- **Good (7-8)**: Good coverage with most landscape elements
- **Adequate (5-6)**: Basic landscape overview
- **Poor (1-4)**: Minimal landscape content
- **Zero (0)**: No landscape report

## Dimension 2: Japanese Report Quality (Weight: 25%)
- **Excellent (9-10)**: Professional Japanese (rich kanji/hiragana/katakana), supply chain terminology (サプライチェーン, 特許, 出願), structured sections, 2000+ chars
- **Good (7-8)**: Good Japanese technical content with structure
- **Adequate (5-6)**: Some Japanese content
- **Poor (1-4)**: Minimal Japanese
- **Zero (0)**: No Japanese content

## Dimension 3: Whitespace Mapping (Weight: 15%)
- **Excellent (9-10)**: 5+ whitespace opportunities identified with IPC references (H01M, C01B, G16C), opportunity assessment levels, Japanese descriptions
- **Good (7-8)**: 3+ opportunities with IPC codes
- **Adequate (5-6)**: Some whitespace identification
- **Poor (1-4)**: Minimal mapping
- **Zero (0)**: No whitespace map

## Dimension 4: IPC Classification (Weight: 15%)
- **Excellent (9-10)**: 10+ IPC codes in correct format, technology taxonomy categories (SE, EL, MF, SY, AP), cross-reference matrix
- **Good (7-8)**: 5+ IPC codes with taxonomy categories
- **Adequate (5-6)**: Basic classification present
- **Poor (1-4)**: Minimal classification
- **Zero (0)**: No classification

## Dimension 5: Completeness (Weight: 20%)
- **Excellent (9-10)**: All deliverables present, dominant IPC identified, filing trends analyzed, answer.json complete
- **Good (7-8)**: Most deliverables with key answer fields
- **Adequate (5-6)**: Some deliverables present
- **Poor (1-4)**: Major gaps
- **Zero (0)**: No output

## Language Quality Assessment
- Target language output must be professional quality Japanese
- No English fallback in patent landscape report
- Technical terminology must follow Japanese patent classification conventions

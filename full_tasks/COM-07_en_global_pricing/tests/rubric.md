# Rubric: COM-07

## Dimension 1: Cross-Validation (Weight: 25%)
- **Excellent (9-10)**: Pricing analysis with USD conversion across all 4 markets (CN, RU, KR, VN), product-level market comparison data
- **Good (7-8)**: USD conversion with 3+ markets and comparison data
- **Adequate (5-6)**: Some cross-market analysis but incomplete conversion
- **Poor (1-4)**: Minimal cross-validation
- **Zero (0)**: No pricing analysis

## Dimension 2: Inconsistency Detection (Weight: 25%)
- **Excellent (9-10)**: Report with 5+ product references (PRD-XXX), percentage gap analysis (5+ percentages), arbitrage opportunities identified, margin violations flagged
- **Good (7-8)**: Report with product references and some percentage analysis
- **Adequate (5-6)**: Basic inconsistency reporting without detailed analysis
- **Poor (1-4)**: Minimal detection
- **Zero (0)**: No inconsistency report

## Dimension 3: Strategy Memo (Weight: 20%)
- **Excellent (9-10)**: English pricing strategy with 4+ sections, market-specific recommendations for all 4 markets, actionable language, 3000+ chars
- **Good (7-8)**: Strategy memo with structure and market recommendations
- **Adequate (5-6)**: Basic strategy memo with limited market coverage
- **Poor (1-4)**: Brief or unfocused memo
- **Zero (0)**: No strategy memo

## Dimension 4: Script Quality (Weight: 15%)
- **Excellent (9-10)**: Valid Python script with FX conversion logic, margin/threshold checking, data loading, and reusable functions
- **Good (7-8)**: Valid script with FX and threshold logic
- **Adequate (5-6)**: Script exists but limited functionality
- **Poor (1-4)**: Script with errors
- **Zero (0)**: No script

## Dimension 5: Data Accuracy (Weight: 15%)
- **Excellent (9-10)**: Correct total products (20), all 4 markets analyzed, valid inconsistency count, most inconsistent product identified
- **Good (7-8)**: Most answer fields correct with reasonable values
- **Adequate (5-6)**: Some answer fields present
- **Poor (1-4)**: Minimal accuracy
- **Zero (0)**: No answer data

## Language Quality Assessment
- Target language output must be professional quality English
- Strategy memo must be primarily in English (>50% Latin characters)
- Technical terminology must be domain-appropriate for pricing analytics

# Подготовка таможенных деклараций на импорт

## Описание задачи

В директории `/workspace/inputs/` находятся документы на поставку товаров из Китая в Россию. Необходимо подготовить полный комплект таможенных деклараций для оформления импорта.

## Входные файлы

- `commercial_invoices_zh.csv` — 5 коммерческих инвойсов от китайского поставщика (на китайском языке)
- `packing_lists_en.csv` — упаковочные листы (на английском языке, вес/габариты)
- `hs_code_reference_ru.json` — справочник кодов ТН ВЭД ЕАЭС (на русском)
- `duty_rates_ru.json` — ставки таможенных пошлин по кодам ТН ВЭД

## Требования

- Классифицировать все товары по кодам ТН ВЭД ЕАЭС (10-значный формат)
- Рассчитать таможенную стоимость каждой партии (метод 1 — по стоимости сделки)
- Рассчитать суммы таможенных пошлин и НДС (20%)
- Подготовить данные для деклараций на товары (ДТ)
- Сформировать итоговые документы:

### Выходные файлы

1. **`customs_declarations_ru.json`** — структурированные данные деклараций:
   - Номер инвойса, отправитель, получатель
   - Товарные позиции с кодами ТН ВЭД
   - Таможенная стоимость
   - Суммы пошлин

2. **`hs_classification.json`** — классификация товаров:
   - Наименование товара (рус.)
   - Код ТН ВЭД (10 цифр)
   - Обоснование классификации

3. **`value_calculation.json`** — расчёт таможенной стоимости:
   - Стоимость товара (FOB)
   - Транспортные расходы
   - Страхование
   - Итого CIF (таможенная стоимость)
   - Пошлина
   - НДС
   - Итого платежи

4. **`declaration_forms_ru.md`** — форматированные формы деклараций на русском языке

## Ключевые параметры

- Общая стоимость поставки: **$47,850** (FOB)
- Транспортные расходы: $3,200 (морской фрахт)
- Страхование: $285
- Итого CIF: $51,335
- Ставки пошлин: 5-15% в зависимости от товара
- НДС: 20% (начисляется на таможенную стоимость + пошлина)

## Результаты

Сохранить все файлы в `/workspace/output/`, итоговую сводку — в `/workspace/answer.json`.

**重要：所有产出必须写入磁盘文件，不要只回复文本。用 bash 命令创建目录、写文件、执行脚本。**

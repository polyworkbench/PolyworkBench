# Rubric: LEG-09

## Dimension 1: Declaration Accuracy (Weight: 30%)
- **Excellent (9-10)**: Russian customs declarations with correct CIF value (~$51,335), proper duty/VAT calculations (20% VAT), all 20 item lines from 5 invoices, HS code classification
- **Good (7-8)**: Most values calculated correctly with proper structure
- **Adequate (5-6)**: Basic declaration with some calculations
- **Poor (1-4)**: Significant calculation errors
- **Zero (0)**: No declarations

## Dimension 2: Russian Language Quality (Weight: 25%)
- **Excellent (9-10)**: Professional Russian (>20% Cyrillic ratio), proper customs terminology, formal register appropriate for official documents
- **Good (7-8)**: Good Russian with customs vocabulary
- **Adequate (5-6)**: Some Russian content
- **Poor (1-4)**: Minimal Russian
- **Zero (0)**: No Russian content

## Dimension 3: Document Completeness (Weight: 20%)
- **Excellent (9-10)**: All required customs forms completed with shipper/consignee info, goods description, values, quantities, origin
- **Good (7-8)**: Most form fields completed
- **Adequate (5-6)**: Partial form completion
- **Poor (1-4)**: Minimal form data
- **Zero (0)**: No forms

## Dimension 4: HS Code Classification (Weight: 15%)
- **Excellent (9-10)**: Correct HS codes assigned to all items based on product descriptions, proper tariff schedule references
- **Good (7-8)**: Most HS codes correctly assigned
- **Adequate (5-6)**: Some HS codes present
- **Poor (1-4)**: Incorrect or missing HS codes
- **Zero (0)**: No HS classification

## Dimension 5: Calculation Accuracy (Weight: 10%)
- **Excellent (9-10)**: FOB ($47,850) + freight ($3,200) + insurance ($285) = CIF correctly calculated, duty and VAT computed properly
- **Good (7-8)**: Most calculations correct
- **Adequate (5-6)**: Some values reasonable
- **Poor (1-4)**: Major calculation errors
- **Zero (0)**: No calculations

## Language Quality Assessment
- Target language output must be professional quality Russian
- No English fallback in official customs documentation
- Technical terminology must follow Russian Federal Customs Service conventions

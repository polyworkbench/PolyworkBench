# トヨタ生産方式（TPS）の基本原則

## 1. ジャスト・イン・タイム（JIT）

ジャスト・イン・タイムとは、「必要なものを、必要な時に、必要なだけ」生産する仕組みである。

### 基本要素
- **タクトタイム**: 顧客の需要に合わせた生産ペース。計算式：1日の稼働時間÷1日の必要生産数
- **連続フロー**: 一個流し（One-piece flow）で工程間の仕掛品を最小化する
- **後工程引取り（プルシステム）**: 後工程が必要な分だけ前工程から引き取る。かんばん方式による管理。

### 適用のポイント
- 平準化生産（へいじゅんか）が前提条件
- 多能工化による柔軟な人員配置
- 段取り替え時間の短縮（シングル段取り＝10分以内）

## 2. 自働化（ジドーカ）

自働化とは、異常が発生した時に機械が自動的に停止し、不良品の生産を防ぐ仕組みである。「にんべんのついた自動化」とも呼ばれる。

### 基本要素
- **異常の検知**: 品質異常・設備異常を自動検知する仕組み
- **ラインストップ**: 異常時に生産を停止する権限と文化（アンドン）
- **原因究明**: なぜなぜ分析（5 Whys）で根本原因を追求

### 適用のポイント
- ポカヨケ（Poka-Yoke）による異常防止
- 目で見る管理（Visual Management）
- 人と機械の作業分離

## 3. ムダの排除（7つのムダ）

### 7つのムダ（Seven Wastes / 七大浪費）
1. **作りすぎのムダ**（過剰生産）: 必要以上に作ること → 最大のムダ
2. **手待ちのムダ**（待ち）: 作業者が材料や前工程を待つこと
3. **運搬のムダ**: 不必要な物の移動
4. **加工そのもののムダ**（過剰加工）: 付加価値のない加工
5. **在庫のムダ**: 必要以上の原材料・仕掛品・完成品
6. **動作のムダ**: 付加価値を生まない人の動き
7. **不良を作るムダ**: 不良品の生産と手直し

### ムダ発見の手法
- 現地現物（Genchi Genbutsu）: 現場で実物を見て判断する
- 作業観察（Work Observation）: ストップウォッチによる作業分析
- スパゲティ・ダイアグラム: 人と物の動線分析

## 4. 改善（カイゼン）

### 基本的な考え方
- **現状に満足しない**: 常により良い方法を追求する
- **小さな改善の積み重ね**: 大きな投資よりも小さな工夫を重視
- **全員参加**: 経営者から現場作業者まで全員が改善に関わる
- **PDCAサイクル**: Plan → Do → Check → Act の繰り返し

### 改善の進め方
1. 現状把握（Data Collection）
2. 問題の明確化（Problem Definition）
3. 真因の追求（Root Cause Analysis）
4. 対策立案（Countermeasure Planning）
5. 対策実施（Implementation）
6. 効果確認（Verification）
7. 標準化（Standardization）

## 5. 設備総合効率（OEE）

OEE = 時間稼働率 × 性能稼働率 × 良品率

- **時間稼働率（Availability）**: (負荷時間 - 停止時間) / 負荷時間
- **性能稼働率（Performance）**: (基準サイクルタイム × 加工数量) / 稼働時間
- **良品率（Quality）**: (加工数量 - 不良数量) / 加工数量

### 世界クラスの目標値
- OEE: 85%以上
- 時間稼働率: 90%以上
- 性能稼働率: 95%以上
- 良品率: 99%以上

## 6. 標準作業

### 三要素
1. **タクトタイム**: 顧客要求に基づく生産ペース
2. **作業順序**: 最も効率的な作業の順番
3. **標準手持ち**: 工程内の最小限の仕掛品数

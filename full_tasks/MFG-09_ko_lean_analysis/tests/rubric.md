# Rubric: MFG-09

## Dimension 1: TPS Application (Weight: 25%)
- **Excellent (9-10)**: Lean analysis report discussing JIT (2+ concepts), Jidoka (poka-yoke/andon), 7 wastes analysis (4+ wastes named), and kaizen approach (2+ terms)
- **Good (7-8)**: Report with 3 of 4 TPS areas covered
- **Adequate (5-6)**: Report with 2 TPS areas
- **Poor (1-4)**: Minimal TPS reference
- **Zero (0)**: No lean analysis report

## Dimension 2: Metrics Analysis (Weight: 25%)
- **Excellent (9-10)**: Metrics comparison with OEE analysis, bottleneck identification (welding/painting), and current vs target values
- **Good (7-8)**: OEE and bottleneck with some comparison
- **Adequate (5-6)**: Basic metrics without bottleneck or targets
- **Poor (1-4)**: Minimal metrics
- **Zero (0)**: No metrics comparison

## Dimension 3: Korean Quality (Weight: 20%)
- **Excellent (9-10)**: Report primarily in Korean (>15% Hangul ratio), Korean manufacturing terms (생산라인, 공정, 개선, 효율, 품질, etc.), improvement plan also in Korean
- **Good (7-8)**: Korean report with some manufacturing terminology
- **Adequate (5-6)**: Some Korean content
- **Poor (1-4)**: Minimal Korean
- **Zero (0)**: No Korean content

## Dimension 4: Improvement Feasibility (Weight: 15%)
- **Excellent (9-10)**: Time-phased plan (short/medium/long term), actionable items (5+), and cost/investment estimates
- **Good (7-8)**: Plan with time phases and some items
- **Adequate (5-6)**: Basic plan without phasing
- **Poor (1-4)**: Minimal plan
- **Zero (0)**: No improvement plan

## Dimension 5: VSM Accuracy (Weight: 15%)
- **Excellent (9-10)**: Value stream map with process steps (stamping, welding, painting, assembly, inspection), cycle/timing data, WIP data, and lead time calculation
- **Good (7-8)**: VSM with steps and timing
- **Adequate (5-6)**: Basic VSM with steps only
- **Poor (1-4)**: Minimal VSM data
- **Zero (0)**: No VSM

## Language Quality Assessment
- Target language output must be professional quality Korean
- No English fallback in analysis report and improvement plan
- Technical terminology must follow Korean lean manufacturing conventions
